# 空白起步：还没有知识库，先搭一个通用工作台

老板还没有知识库、又想先把工作台用起来时，搭一个空白的通用版：首页、待办、收件箱这些先能用，客户、项目边用边录。以后建好知识库，再说“工作台接上我的知识库”。

## 先问一句

读不到知识库（kb_scan 输出 `kb: false`，或者老板说“我还没有知识库”）时，先问：

> 你还没有知识库。两条路：① 先建知识库（用老板知识库 Skill，一个多小时，建好以后工作台首页就是你自己的客户和要事）；② 先搭一个空白的工作台，今天就能用，客户、项目边用边录，以后建好知识库再接上。选哪个？

选 ① 就交给 boss-kb。选 ② 往下走。

## 和按知识库搭有什么不一样

| | 按知识库搭 | 空白起步 |
|---|---|---|
| 放在哪 | 知识库根目录下的 `工作台/`（在云盘里时程序放库外） | 一律放库外：Mac `~/老板工作台/<称呼或店名>/`，Windows `%USERPROFILE%\老板工作台\<称呼或店名>\`；`README.md`、`搭建确认/`、`快照/` 都在这个文件夹里 |
| 复述 | 六块，从知识库读 | 只有两块：你是谁、做什么；你每天最在意的。先在对话里问老板四句话（见下），出处写“这次对话” |
| 模块 | 按类型画像和资料推荐 | 默认：今日（必选）、待办与日程、收件箱、客户跟进、项目；老板说了生意类型，再按 `模块目录.md` 的“类型画像 → 默认推荐”加，需要外部数据的标“稍后接数据”。知识库页标“资料不够”，说明“建好知识库后接上” |
| 导入 | 从知识库导入客户、项目、待办 | 不导入；空状态写清“点右上角新建，或者对 Codex 说‘记一个客户’” |
| AGENTS.md | 在知识库 AGENTS.md 加一小段工作台说明 | 没有知识库，不写任何 AGENTS.md，也不建 `.ignore` |
| 往知识库写 | 三种写 | 没有知识库可写；新材料先存在工作台自己的收件箱 |

## 问老板的四句话（在打开确认页之前）

1. “怎么称呼你？”
2. “你现在主要做什么？一句话。”（生意、内容、服务都行）
3. “早上打开电脑，最想先看到哪一两件事？”
4. “有没有一定要用上的东西？比如每天要跟的客户、每周要交的东西。”

不追问，答不上来的写“以后再说”。电脑几点开、几点想看汇总，在确认页第四步问，这里不问。

## 写 recommendations.json

- 照 `确认页数据格式.md` 写，`kb` 那一项不写（确认页只要求 `boss`、`profile`、`modules`、`themes`、`schedule`）。
- `profile` 只放两块：`who`（你是谁、做什么）、`cares`（你每天最在意的），`sources` 写 `["这次对话"]`。
- `wants` 用四句话的第 3 句（“早上最想先看到哪一两件事”）生成：一句话拆成一两个选项，`selected: true`，`module` 填对应的模块 id（例：“今天要交的订单”→ `tasks`）。第 3 句答“以后再说”就不写 `wants`，确认页第二步不显示“最想先看到”那一行。
- `notes` 放一条 info：“还没有知识库：先用起来，以后说‘工作台接上我的知识库’，客户和项目会自动对上。”
- 模块预览不编数据：没有真实资料的模块用 `empty` 预览，写清“搭好以后在这里新建”。

## 搭建

照 `搭建步骤.md` 做，有这几处不同：
- 第 0 步“定位置”直接用库外位置，不问云盘。
- 第 3 步“从知识库导入”整步跳过。
- 第 6 步只写 `README.md`，在开头注明“还没接知识库”；不改任何 AGENTS.md，不建 `.ignore`。
- 第 7 步验收时，空模块显示的是空状态和新建入口，不算报错。

## 以后接上知识库

老板说“工作台接上我的知识库”“知识库建好了，接到工作台”：

1. 问清知识库在哪，跑 `kb_scan.mjs "<知识库>"`。
2. 只读对照工作台里已有的客户、项目、待办和知识库里的（按名称和别名对），列一张表：哪些两边都有、哪些只在知识库、哪些只在工作台。
3. 老板说“确认”后，用工作台命令把只在知识库里的导进来；两边都有的不覆盖，有出入的列给老板选。只在工作台里的客户、项目，提议用 boss-kb 补进知识库，不在这里写。
4. 在知识库 AGENTS.md 加工作台那一小段（照 `搭建步骤.md` 第 6 步，程序在库外，写完整路径），先给老板看，他说“确认”再写。
5. `README.md` 开头改成“已接知识库：<路径>（日期）”，“改动记录”加一行。
6. 以后照常按知识库来：每天的流水在工作台，往知识库写只做三种写。
