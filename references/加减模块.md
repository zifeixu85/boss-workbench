# 加模块、减模块、改功能

工作台搭好以后，老板会不断冒出新需求。这个 Skill 让每次改动都可控：说清楚 → 看样子 → 再动手 → 验收 → 留记录。

**路径约定**：下文的 `工作台/` 指工作台所在的位置。知识库在 iCloud、网盘里时，程序和数据库在库外（例如 `~/老板工作台/<店名>/`），以 `工作台/README.md` 里写的为准。空白版在 `~/老板工作台/<名字>/`（Windows 是 `%USERPROFILE%\老板工作台\<名字>\`），下文的 `工作台/` 就是这个文件夹。下面提到的参考文件和这份在同一个 `references/` 文件夹。

## 第 0 步：先看现在的工作台

读 `工作台/README.md`：地址、程序在哪、已有哪些模块、改动记录、老板的补充、“以后想加”。没有这份文件，说明工作台还没搭，先按 SKILL.md 搭工作台。

## 第 1 步：三行需求

把老板的话整理成三行，复述给老板确认：

1. **要什么**：哪个页面、看到什么、能做什么（例：“经营里加一个天猫页，看每天成交、推广花费和 ROI”）。
2. **什么不能动**：已有的页面、数据、习惯（例：“首页布局不变；已有的客户数据不动”）。
3. **怎么算好**：老板能自己检验的标准（例：“打开天猫页能看到最近 30 天每天的成交，点开任何一个数都能看到是哪次导入的”）。

老板说得太笼统（“做个好看点的数据页”），最多问 3 个问题；能从知识库和工作台现有数据推断的不要问。

## 第 2 步：模块卡

在 `工作台/模块卡/<日期>-<模块名>.md` 写一张卡（模板见 [模块卡模板.md](模块卡模板.md)）：解决什么、放在导航哪里、有哪些页面、每页放什么、数据从哪来、字段、提醒、哪些不做。数据来源按 [数据来源.md](数据来源.md) 的顺序选：已有数据 → 导入文件（AI 对字段）→ 飞书多维表格 → RSS → 开放平台接口 / MCP；RPA、爬虫不在这里做。

## 第 3 步：样张

先在工作台里做一个只读样张页（用示例数据或老板的真实数据），打开给老板看：“大概是这个样子，哪里要改？”老板点头再开发。小改动（改文字、挪位置）可以跳过样张，直接改完给老板看前后对比。

## 第 4 步：开发

- 先读工作台程序文件夹里的 `规范/README.md` 和它链接的几篇；只用规范里的组件和设计令牌，网页里不用宋体。
- 改动范围只在：`src/features/<模块>/`、`server/` 里这个模块自己的文件、新编号的迁移文件、`src/app/nav.ts` 里加一个入口。要动公共文件，先说明为什么。
- 详情用右侧抽屉（地址栏参数），新建用弹窗，页内视图用 ViewTabs，看板卡片不放改状态的下拉（拖动或抽屉里改）。
- 网页和 Codex 走同一套业务规则：新增数据都加对应的命令行命令（`server/cli.ts`），不直接写 SQL。
- 改前备份：把数据库复制一份到程序文件夹里的 `备份/`，文件名带日期和时间；改坏了能回去。备份跟着程序走：知识库在云盘里时程序在库外，备份不会被同步上去。不放 `工作台/快照/`，那里是工作台导出给别的对话读的。

## 第 5 步：验收

- 在程序文件夹里跑 `npm run build` 和 `npm run doctor`，都通过。
- 按“怎么算好”逐条检查，截图给老板看。
- 告诉老板：改了什么、怎么用、没做什么。

## 第 6 步：留记录

在 `工作台/README.md` 的“改动记录”里加一行：日期、三行需求、改了哪些文件、怎么回退。

## 减模块、换顺序

老板说“这个模块用不上了”“导航太多了”：
1. 先确认拿掉哪个；告诉老板“代码和数据都留着，只是从导航里拿掉，想要随时加回来”。
2. 改前照第 4 步备份数据库；只改 `src/app/nav.ts` 里这一项（或设置里的模块开关，以模板为准），不删功能文件夹、不删数据。
3. `npm run build`、`npm run doctor` 通过，打开首页给老板看。
4. 在 `工作台/README.md` 的模块清单里标“已收起（日期）”，“改动记录”加一行。

## 规矩

- 不编数据：老板没给的数字不填；示例数据只在演示模式。
- 客户承诺、报价、成交、回款，写入前给老板确认。
- 知识库原文不改；模块需要的知识（方法、话术、口径）从知识库读，缺了提示用 boss-kb 补。
- 模块要往知识库写，只做三种写：客户或项目文件的“往来记录”末尾追加一条（写明 `来源: 工作台`）（就地建图的库：老板原有的文件不追加，写进同一文件夹的 `<客户名或项目名>-往来记录.md`，类型 往来记录）；新材料放进 `00-收件箱/`；在 `90-持续生长/待确认的发现.md` 追加一条发现。别的改动先提议，老板确认后交给 boss-kb 写。
- 外部数据的账号、密钥只放本机环境变量或系统钥匙串，不写进文件、不进截图。
