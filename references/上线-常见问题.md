# 常见问题

> 依据见 [CloudBase接入与开通.md](CloudBase接入与开通.md)；标“未核实”的，以控制台实际显示为准。

## 排查口诀（先对一遍）

| 现象 | 先查 |
|---|---|
| 看不到 CloudBase 工具，或报 `-32001` 超时 | 完全退出 Codex 再打开；还不行换腾讯镜像（见下面“接入和部署出错”） |
| 设备码登录点了授权却没成功 | 是不是用 Safari 打开的：换 Chrome 或 Edge；授权网址有没有被截断 |
| 登录了却显示“没有环境” | 是不是用**国内站**（cloud.tencent.com）登录的；环境是不是在别的地域（`queryEnv` 的 `list` 只查当前地域） |
| 上传失败 | 静态网站托管开通了没有（`queryHosting(action="status")`）；环境是不是**上海**；工具写法是不是旧的（`uploadFiles` 已改成 `upload`） |
| 改完手机上还是旧的 | 链接后面换一个新的 `?v=`；或者等 CDN 几分钟 |
| 打开是空白页、或刷新后 404 | 链接里有没有 `index.html`；用模板打包的，路径是不是相对路径、是不是哈希路由 |
| 打开后提示下载文件 | 是不是直接点链接或扫码打开的（别的方式请求，平台会让浏览器下载）；手机系统太旧（iOS 16.4 以前）也会这样，换新一点的手机或用电脑看 |
| 返回 514 或“访问量异常” | 碰到访问频率限制了：别让很多人同时开同一个链接，过一会再试。（“514”出自插件文档；官方中间页说明里没有这个数，也没写具体频率，只说访问量异常波动时可能禁止访问） |
| 输口令一直说“不对” | 口令前后多了空格不要紧（会自动去掉）；全角半角、繁简字要和定的时候一样 |
| 输了口令页面不动、或提示“打不开加了口令的页面” | 换手机自带浏览器；还不行就是平台改了网页内容、解密脚本被拦了：先撤下，或者问过老板后改用不加锁的版本（内容照样打码、只放默认几块） |

## 实名认证

- **要不要做**：要。官方原话：腾讯云账号“需要完成账号实名认证才能购买和使用云产品”。静态托管的快速开始也把实名写在前置条件里。
- **个人还是企业**：推荐用**个人认证，微信扫码**，几分钟能完成，人要在场、用自己的手机。以后要开增值税专用发票、要把东西归到公司名下，再改成企业认证。个人可以改成企业，**企业改不回个人**。
- **企业认证为什么慢**：要法人配合（法人微信扫码、法人人脸），或者对公打款、微信公众平台认证，当天往往做不完。
- **审核没通过 / 卡住**：按页面提示重来；还不行让老板联系腾讯云客服。Codex 不替老板填身份证号、不上传证件照片。
- **用别人的微信扫可以吗**：不行。实名的是账号主人本人，账号以后出了问题要本人处理。

## 免费额度和到期

- **会不会花钱**：跟老板这样说：“免费版不能开按量付费，也不自动续费；只要不点购买、升级、续费，就不花钱。”额度用完或到期，服务就停。（官方没有直接写“不扣费”。）真正要防的是老板手误点进付费档、升级成个人版（升级后**降不回**免费版），或者 Codex 调了建环境、升级、续费的工具——本 Skill 禁止调这些。
- **选了公司的付费环境**：账号下有小程序或公司在用的付费环境时，传到那个环境，静态托管的流量按量收费。默认选免费环境；选别的要老板先知道“可能有小额费用”。
- **额度够不够**：每月 3000 资源点，约合 3 元。手机页几十 KB，自己和几个合伙人看，绰绰有余（估算）。别把链接发到大群。
- **用完了怎么办**：额度用完服务就停；是不是下个月自动恢复**未核实**，以控制台为准。要不要升级由老板自己决定，Codex 不替他点。
- **到期了**：到期后进入停服隔离期，没转付费就销毁环境（隔离期多长**未核实**）；链接就打不开了。到期前 1 个月内可以在控制台手动续 6 个月，不自动续。官方博客还有“发一篇分享、审核通过换 6 个月”的活动，以活动页为准。
- **到期日在哪看**：`queryEnv(action="info", envId="<环境ID>")`（必须带 envId）的计费信息 BillingInfo 里有 ExpireTime 就用；没有就请老板在云开发控制台的环境详情里看，记进 `工作台/手机版/记录.md`（说不清就记“未知”）。首次有效期多长**未核实**。
- **老账号建不了免费环境**：每个账号只能有 1 个免费环境；以前用过云开发免费套餐的，要先付费或销毁旧环境才能再建。有旧环境就直接用旧环境。
- **环境不在上海**：静态网站托管只支持上海。**不要再建环境**（第二个要花钱），也别自己删了重建（兑换码一次性）。停下，告诉老板静态托管要在上海地域的环境，请他到控制台确认这个环境的地域、能不能开静态网站托管，再定怎么办。
- **兑换码哪里领**：官方写“兑换码领取方式详见购买页说明”，没登录看不到，**未核实**。带老板走到那一页，照页面说明做。

## 手机打不开

按顺序查：

1. **链接完整吗**：微信里长链接有时被截断。用二维码，或把链接整段复制。
2. **先出了腾讯云的提示页**：正常，点“确定访问”。确认后一段时间内不再弹（时间由平台定）。
3. **有口令锁**：输口令。提示“这个浏览器打不开加了口令的页面”，换手机自带浏览器，确认网址是 `https://` 开头。
4. **在微信里打开**：微信内置浏览器会不会再多一层拦截，**未核实**（还没实测）。测过之前，默认请人用手机相机扫、在手机浏览器里打开；已经在微信里了，点右上角“…”→“在浏览器打开”。
5. **空白页 / 404**：链接里带上 `index.html`；刚上传的等一两分钟；用 `queryHosting(action="findFiles", prefix="m-xxxxxxxx/")` 看文件是不是真在那个文件夹里。
6. **旧内容**：换一个新的 `?v=`；CDN 缓存一般几分钟。
7. **514 或“访问量异常”**：默认域名有频率限制，很多人同时开会被限；平台也可能直接禁止访问。别发到群里。
8. **环境到期、停服**：见上一节。

## 测试提示页（“访问提示”中间页）

- **是什么**：腾讯云对默认域名（`xxx.tcloudbaseapp.com`）加的风险提示。浏览器直接打开时先显示它，点“确定访问”才进页面。官方说它“将作为一项软性安全提醒长期存在”（2025 年 9 月发公告，之后对新环境生效）。
- **能不能去掉**：免费版去不掉。换成插件的“应用部署”拿到的独立子域名也去不掉（插件文档）。要去掉只能升级付费版、绑一个已经 ICP 备案的自己的域名——本 Skill 不做。
- **怎么认“直接打开”**：平台按浏览器发的 `Sec-Fetch-Mode: navigate` 请求头判断；不是直接打开的会被当成下载。所以链接要直接点开或扫码打开，太旧的手机可能不行。
- **跟老板怎么说**：“第一次打开会先出腾讯云的提示页，这是平台对测试网址的统一提醒，点‘确定访问’就行，不是中毒，也不是我们的页面坏了。”
- **为什么不能当正式网站**：官方说默认域名“仅适用于开发测试阶段”，“严禁用于正式生产环境或分发给大规模用户”，访问量异常时平台可以禁止访问。

## 自定义域名和备案

- 免费体验版**能绑的自定义域名是 0 个**；个人版 1 个，标准版 5 个。
- 绑之前域名必须**已完成 ICP 备案**，还要 SSL 证书。备案一般要几天到几周，要真实主体信息。
- 拿云开发环境去备案：要套餐支持备案、剩余有效期超过 6 个月、开启云托管固定 IP（插件文档，官网原文**未核实**）。
- 跟老板只提一句：“以后要对外正式用，再买套餐、备案、绑自己的域名。”

## 接入和部署出错

| 现象 | 怎么办 |
|---|---|
| 装完插件看不到 CloudBase 工具 | **完全退出 Codex 再打开**，在同一个知识库项目里新开对话（只新开线程常常不够，作者实测，2026-10）；先跑 `preflight.mjs` 看插件是不是被停用了 |
| 新开对话还看不到工具，或报 `-32001 Request timed out`、工具数量为 0 | 插件每次启动都现下载最新版，网络慢就超时。在终端运行 `npm config set registry https://mirrors.cloud.tencent.com/npm/`（会改这台电脑所有 npm 的下载源），重启 Codex；Mac 用 nvm 装 Node 的先设好默认 Node 版本；Windows 还不行就改用“只接 MCP”的 `cmd /c` 接法（接入文档 1.2） |
| 报 `ENOTFOUND registry.npmjs.org` | Codex 问联网权限时点允许；公司网络有代理的先确认能上 npm |
| 插件市场添加失败（拉不下 GitHub） | 用备用接法“只接 MCP”（见接入文档 1.2），npm 换腾讯镜像 |
| 上传报参数错（比如 `uploadFiles` 不认、多了 `envId`） | 工具名变了。按工具自己的参数说明改写法（现在是 `manageHosting(action="upload", localPath, cloudPath)`），**不换别的部署方式** |
| 插件建议用 `deployApp` / “应用部署” / `/cloudbase-deploy` | 不用。本 Skill 只用 `manageHosting(action="upload")` 上传 `dist-mobile/` |
| 文件传到了别的环境 | 上传只进“当前绑定的环境”。用 `auth(action="status")` 看绑的是哪个，不对就 `auth(action="set_env", envId=…)`，再传；传错的那份请老板确认后删掉 |
| 导出时报“读工作台数据没成功” | 按提示：Node 要 22.18 以上；Codex 问权限点允许；在工作台程序文件夹里跑 `npm run doctor` |
| 导出时报“多出来……要用英文双引号” | Windows PowerShell 把没加引号的 `待办,日程` 拆开了。写成 `--sections "待办,日程"` |
| 打包时报“没打包：正文里还有不能上传的内容” | 快照里漏了真名或号码。用 `--extra-names` 补上，或改掉工作台里的原文，重新导出再打包 |
| 自检没通过 | 按“必须先改”逐条改，从导出或打包那一步重来，不要跳过自检直接传。有口令锁时记得带 `--snapshot` |
| 上传到了网站根目录 | 让老板确认后只删根目录里刚传的那个文件（不要用 `isDir` 删 `/`），重新传到 `m-xxxxxxxx` |
| 撤下时发现云上有好几个 `m-` 文件夹 | 以前上传了没记上。`queryHosting(action="findFiles", prefix="m-")` 列给老板看，他点名要删的，一个一个按文件夹名删 |

## 其他

- **链接被转出去了**：马上“把手机版撤掉”（删云上那个文件夹，5—10 分钟后彻底打不开）；要继续用，重新上线会换一个新文件夹、新链接，有口令锁的顺便换口令。
- **忘了口令**：口令没写进工作台和网页文件。重新打包时换一个口令，传到同一个文件夹覆盖。
- **口令会不会泄露**：口令不写进工作台、知识库和网页文件，但老板在对话里说过的口令、命令行里用过的口令，都会留在本机 Codex 的对话记录里（`~/.codex/sessions/`）。所以别用在别处用过的密码。
- **想看“客户F”是谁**：查本机的 `<工作台>/手机版/对照表-<日期>.json`；或者导出时选“首字”打码，自己认得出。
- **想实时看、在手机上改**：只读手机版做不到，需要另做登录保护版（本 Skill 不含；数据放云数据库，登录后读写）。
- **几个合伙人各自登录**：静态托管做不到按人收回权限，需要另做登录保护版（本 Skill 不含）。
