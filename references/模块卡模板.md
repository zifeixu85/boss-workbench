# 模块卡模板

复制下面的内容到 `工作台/模块卡/<YYYY-MM-DD>-<模块名>.md`，填完给老板看。

```markdown
# 模块卡：<模块名>

## 三行需求
- 要什么：
- 什么不能动：
- 怎么算好：

## 放在哪
- 导航分组：日常 / 客户 / 经营 / 内容 / 资料（数据源与导入放“资料”）
- 菜单名：
- 子页面（如果有）：

## 每页放什么
| 页面 | 第一屏看到什么 | 能做什么 | 详情怎么打开 |
|---|---|---|---|

## 数据
| 数据 | 从哪来 | 多久更新一次 | 谁来写（网页 / Codex 命令 / 定时任务） |
|---|---|---|---|

字段：
- 表名：字段（类型，说明）

## 提醒
- 什么时候提醒、提醒谁、点开去哪

## 不做什么
- （写清楚这次不做的，避免越做越大）

## 验收
- [ ] 怎么算好里的每一条
- [ ] build、doctor 通过
- [ ] 手机宽度能看
```
