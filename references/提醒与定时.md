# 提醒与定时

**默认不提醒、不自启**（A梦 2026-10-15 定）：新搭的工作台是手动打开的，老板在确认页第四步勾了“开启提醒”才提醒，勾了“开机自动启动”才设自启，两样分开选。没勾的，搭建时先 `remind-set --off`（模板默认是开的），以后老板想要，在设置页打开或跟 Codex 说一声。

开了提醒的，最后告诉老板两句话：“第一次打开点‘开启提醒’，浏览器问你时点允许”“电脑开着、工作台开着才能按时提醒”。

模板里已经做好（代码在 `server/reminders/`、`scripts/autostart.mjs`），搭建时按第 5 步的命令设，不用再写代码。

## 提醒走两条路

工作台后台服务每 30 秒按规则算一遍（不靠页面开着），新出来的提醒记进数据库 `reminders` 表，再按下面选一条路弹：

| 老板在哪 | 怎么提醒 | 实现 |
|---|---|---|
| 工作台页面开着、点过“开启提醒” | 浏览器通知，点一下打开对应页面并标已读 | 页面连实时通道（SSE）时带 `?notify=on`，服务端把提醒推过去，页面用 `Notification` 弹。127.0.0.1 算安全来源。权限只在老板点“开启提醒”时申请（今日页顶上、设置页、提醒页都有这个按钮）；Safari 只认点击里直接申请的。光有通知权限不算，这个浏览器里点过“开启提醒”才弹（免得以前给过权限的浏览器一打开页面就弹） |
| 页面关了（或切到后台超过半分钟、没允许通知），电脑开着 | 电脑系统通知 | 后台服务直接发，只用系统自带的程序：Mac 用 `osascript` 的 `display notification`（标题、正文当参数传，不拼进脚本）；Windows 用系统自带 PowerShell 5.1 的 `Windows.UI.Notifications` 弹 Toast，弹不出来退回任务栏气泡提示，再不行只记日志；其他系统只记日志 |

- Mac 的系统通知显示为“脚本编辑器”发的，**点了只会打开“脚本编辑器”，打不开工作台的页面**（osascript 做不到；要能点开得装第三方的 terminal-notifier，我们不装）。第一次可能要在“系统设置 → 通知 → 脚本编辑器”里允许。通知标题是“老板工作台 · <店名>”，副标题是提醒的事。
- Windows 的 Toast 显示为“Windows PowerShell”发的，带了网址，点了用浏览器打开对应页面。“设置 → 系统 → 通知”里关了 PowerShell 的通知就弹不出来。**Windows 这一路还没在真机上测过**，正式用之前在中文 Windows 上用 `remind-test` 试一次。
- 两条路都没弹成（关了、免打扰、演示模式、系统通知出错）的，照样记在网页“提醒”页，写着原因。

共同前提：电脑开着、已登录、没睡眠，工作台后台服务在跑（手动打开的，开机后要先双击启动；勾了开机自启的会自己跑）。合盖、睡眠、关机时都提醒不了；想一直在线要把工作台部署到云上（选做）。

不用浏览器的网页推送（Web Push）：要经过浏览器厂商的推送服务，Chrome 的推送服务在国内网络下时通时断，还要配密钥。飞书机器人推到手机：程序里还没有，要的话按 `加减模块.md` 另做。

## 提醒什么

| 规则 | 什么时候 | 只提醒一次的依据 |
|---|---|---|
| 待办到期 | 填了“到期时间”的待办：到期前 1 小时（建的时候已经不到 1 小时就马上提醒；过了 30 分钟还没做也补一次） | 待办 + 到期日期时间（改了时间会再提醒） |
| 日程 | 不是全天的日程：开始前 15 分钟（开始后 10 分钟内也补） | 日程 + 开始时间 |
| 客户跟进 | “下次跟进”是今天的客户：早上（免打扰结束时，默认 8:00）以后 | 客户 + 日期 |
| 经营异常 | 新出现时（经营模块算出来的异常） | 异常 + 这一段的第一天（连着几天都在只提醒一次；消失两天以上又出现，再提醒） |
| 数据源 | 没按时更新、导入失败 | 来源 + 日期（每天最多一次） |
| 看汇总 | 每天老板说的时间（确认页第 4 步，`notify_at`）；没设：工作台开了 5 分钟后 | 日期 |

- 只有日期、没有时间的待办不单独弹，算进每天的汇总（“今天有 3 件待办到期”）。
- 同一刻出来好几条：同一类合成一条弹（“今天该跟进 3 位客户”），一次最多弹 3 条，多的合成“还有 N 条提醒”；“提醒”页里一条一条都有。
- 那个时间电脑没开：开机后工作台起来，当天该提醒的（汇总、跟进、还在窗口里的待办和日程）马上补；免打扰时段里不补汇总。
- 免打扰时段里：过了免打扰还在提醒窗口里的（比如 8:30 到期的待办、还在的异常）先不记，免打扰一结束（8:00）照常弹；免打扰结束前窗口就过了的（半夜 3 点到期的待办），只记不弹。

## 怎么不打扰

都在网页“设置 → 提醒”里，命令行用 `remind-set`：

- **总开关**：关了照样记在“提醒”页，只是不弹。
- **免打扰**：默认 22:00—08:00 不弹（可以跨午夜）；到早上还有效的留到免打扰结束再弹，到早上就过时的只记。老板说的开机时间更早时，结束时间改成开机时间（`remind-set --quiet 22:00-07:30`）。
- **每天看汇总**：`notify_at`，确认页第 4 步的时间。
- **演示模式**（数据库里有演示日期 `demo_today`）：照样按演示日期算、记下，默认**不弹电脑系统通知**（免得演示时在讲台电脑上乱弹）；点过“开启提醒”的页面照样有浏览器通知。设置里“演示时也弹电脑系统通知”打开后才弹。演示前想让异常、跟进这些重新弹一次：`remind-clear --yes` 清掉提醒记录。

## 每天几点准备好

老板在确认页勾了“开启提醒”，再选几点看汇总，`result.json` 的 `schedule` 里是 `mode: reminders` 和 `notify_at`：

1. 今日页的数是打开时现算的，工作台本身不需要提前“整理”。
2. `notify_at` 写进工作台设置（`remind-set --on --at 8:30`），到点弹“今天的汇总好了”。
3. 选“一开电脑就看”（`notify_at` 为空）：`remind-set --on --at none`，工作台启动 5 分钟后提醒一次。注意这不是“关掉”；关掉是 `remind-set --off`。
4. 确认页不建 AI 定时任务（`prepare_at` 总是空的）。要 AI 每天写经营日报、选题，另外问清写什么、几点，老板同意了再建 Codex 定时任务，通过工作台命令写回，提示词写进 `工作台/README.md`。

## 开机自动启动

只有老板勾了“开机自动启动”才设。用安装脚本，一条命令（在 `<程序位置>` 里运行；程序在知识库外时照样带上 `WORKBENCH_ROOT`、`WORKBENCH_DB`，会一起写进自启配置）：

```bash
node scripts/install.mjs --autostart on --name abc   # 打开：马上在后台启动，以后每次登录自动开。--name 是英文短名，不写就用知识库文件夹名里的英文字母，再没有用 wb-<端口>
node scripts/install.mjs --autostart status          # 现在是开是关、在不在运行（进程号）、网页能不能打开、日志在哪
node scripts/install.mjs --autostart off             # 关掉（后台服务也一起停）
```

打开以后，工作台文件夹（程序的上一层）里会多一个“关掉开机自启”（Mac 是 `.command`，Windows 是 `.bat`），老板双击就能关。`npm run doctor` 的结尾也会报告开机自启的状态。

**Mac（登录项服务 LaunchAgent）**：写 `~/Library/LaunchAgents/com.boss-workbench.<短名>.plist`，用 `launchctl bootstrap gui/<用户号>` 加载、`launchctl bootout gui/<用户号>/<Label>` 卸下。要点：

- `ProgramArguments` 是安装时那个 node 的完整路径（`process.execPath`，nvm 装的也对）+ `server/index.ts`；`WorkingDirectory` 是程序文件夹；环境变量带 `PORT`、`PATH`（和装的时候一样，后台服务找得到 codex），程序在库外时带 `WORKBENCH_ROOT`、`WORKBENCH_DB`。
- `KeepAlive` 只在出错退出时重启（`SuccessfulExit = false`）：端口被占时工作台说一句“已经在运行”就正常退出，不会每 10 秒重启一次。所以开着自启时**用 kill 停不掉**（出错退出会被拉起来），要用 `--autostart off`。
- 日志：`<程序位置>/日志/服务.log`、`服务-错误.log`。
- 已经有一个工作台开着（比如双击“启动工作台”开的）时，`on` 只写配置、不再加载第二个，提示“下次登录自动开”。
- Mac 会拦后台程序读“桌面”“文稿”“下载”和 iCloud 云盘里的文件。程序或知识库放在这些地方时，后台服务第一次读文件可能弹“node 想访问……”，要点允许；没弹框又读不到（日志里有 `Operation not permitted`），就到“系统设置 → 隐私与安全性 → 文件和文件夹”里给 node 打开。装好后重启一次电脑，用 `--autostart status` 确认服务自己起来了。

**Windows（任务计划，登录时运行）**：在程序文件夹生成两个文件，再建任务：

- `启动工作台.bat`：UTF-8 不带 BOM，第二行 `chcp 65001 >nul`（路径里有中文时 cmd 才读得对）；`cd /d` 到程序文件夹、建 `日志`、`set PORT=…`（库外时再 set 两个环境变量），用 node 的完整路径运行 `server\index.ts`，输出追加到 `日志\服务.log`。
- `启动工作台.vbs`：UTF-16（带 BOM），一行 `CreateObject("WScript.Shell").Run """<bat>""", 0, False`，隐藏窗口运行 bat，登录时不会闪黑窗口。
- 任务：先写一份任务计划 XML（UTF-16），再 `schtasks /Create /TN "老板工作台" /XML <那份 XML> /F`，建完删掉 XML。不用 `/SC ONLOGON` 的默认设置：它“用电池时不启动、切到电池就停、运行 72 小时就结束”，笔记本上会开不起来。XML 里写：当前用户登录时（`LogonTrigger` + `UserId` = 域\用户名）、普通权限（`LeastPrivilege`）、用电池也启动、切到电池不停、不限运行时长（`PT0S`）、同时只跑一个；动作是 `wscript.exe "<程序位置>\启动工作台.vbs"`，工作目录是程序文件夹。有的电脑建“登录时运行”的任务要管理员，建不了就退回“启动”文件夹（`shell:startup`）里放一个指向这个 vbs 的快捷方式“老板工作台.lnk”。
- `off`：删任务和快捷方式、删这两个文件，再按端口找到工作台的进程结束掉。
- **Windows 这一路没在真机上测过**（只在 Mac 上用假的 schtasks 测了生成的文件和参数）。

课程包的装环境工具“清空课程环境”认的正是这几样：Label 以 `com.boss-workbench.` 开头的 plist、任务计划“老板工作台”、启动文件夹里指向“启动工作台”的快捷方式；名字别改。

## 告诉老板怎么停、怎么删

在 `工作台/README.md` 写一节《怎么停、怎么删》（人话，模板说明里有现成的一段可以照抄改路径）：

1. 暂停提醒：设置 → 提醒 → 关掉“到点提醒”（照样记，不弹）。只是晚上别吵：改免打扰时段。
2. 关开机自启：双击工作台文件夹里的“关掉开机自启”，或在程序文件夹运行 `node scripts/install.mjs --autostart off`（后台服务一起停）。
3. 停后台服务：开了自启的，用上面那条；没开自启、是双击“启动工作台”开的，关掉那个窗口就停了。
4. 日志在 `<程序位置>/日志/`（自启的后台服务）；`--autostart status` 会说在哪。
5. 卸载两个 Skill（老板知识库、老板工作台）：双击课程包里的“装环境”，选 3“清空课程环境”（会顺带把开机自启关掉；全部挪进备份、不删除）。知识库和工作台的数据不动。
