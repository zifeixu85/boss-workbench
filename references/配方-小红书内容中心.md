# 配方：小红书内容中心

适合靠内容获客的老板。工作台负责“看”和“管”：今天发什么、选题、排期、每篇的样子和数据、复盘；写稿时在创作页和 AI 对话（只有创作页有对话窗口），背后由模块自带的写作规则（见 `配方-小红书内容中心-写作规则.md`，搭模块时放进知识库的 `.agents/skills/xhs-creator/`）按知识库里的账号定位、口吻、方法卡和红线来写。多人协作、积分、平台接口不在这个配方里。

## 三行需求（示例）
- 要什么：每天早上看到 10 个选题和本周排期；挑一个进创作页，左边和 AI 对话、右边看稿件和手机上的样子；发出去的笔记能看数据（自然和投流分开）；每周复盘一次。
- 什么不能动：知识库原文（复盘出的经验，确认后才写回）；不替我发布。
- 怎么算好：一句话“写一篇降温喝白茶的”，3 分钟内右边出现能直接发的稿件和手机预览，而且没有功效词、没有客户名字、没有提前说新品名。

## 页面（5 个子页）

| 子页 | 有没有对话 | 放什么 |
|---|---|---|
| 今天 | 没有（只有一句话入口） | “今天发这篇”大卡（手机缩略预览 + 状态 + 继续写 / 看预览 / 标记已发布）；一句话入口 + 4 个起点（从今天的选题 / 从旧笔记翻新 / 从一款茶开始 / 从对标笔记开始）；本周排期（7 天）；今日选题（来源标签 + 为什么做，“就做这个”“先放进已选”）；数据提醒 2—3 条 |
| 内容 | 没有 | ViewTabs：看板（灵感池 → 已选 → 写稿中 → 待发布 → 已发布，拖动）/ 日历（月、周，拖动改排期）/ 列表（表格） |
| 创作 | **有，且只在这里** | 左约 40%：起点卡（为什么做这篇、AI 手上有什么资料，可点开看原文）、对话、进行中的状态、快捷建议、输入框；右约 60%：页签 稿件 / 预览 / 封面 / 版本，右上“已保存 · v3” |
| 数据 | 没有 | 时间、流量（全部 / 自然 / 投流）、形式、内容支柱筛选；自然、投流两张汇总卡；内容支柱 × 篇均收藏（只算自然流量）；按周的篇均赞藏和发布篇数（两张图，同一时间轴）；笔记表格 |
| 复盘 | 没有 | 按周列表（第 43 周 · 10/19—10/25：未复盘 / 已复盘）；“生成复盘”→ 指标、总结、做得好的、要改的、下周选题建议（放进灵感池）、可沉淀的经验（每条带依据和样本数；老板点“存进知识库”后，追加到 `90-持续生长/待确认的发现.md`，由 boss-kb 整理进规律或方法卡） |

**单篇抽屉**（`?piece=`）在今天、内容、数据、复盘都能打开：左边手机预览，右边按状态显示发布前检查或发布后数据（第 1、3、7 天）。

## 手机预览
- 发现页：双列瀑布流，这篇用红框标出，旁边是自己最近的笔记。
- 图文笔记页：顶栏（账号头像、关注）、3:4 图片轮播（封面 + 内页，右上 1/N）、标题、正文、话题。
- 封面默认用模板实时画：大字 + 茶具垫图 + 品牌色（3:4），不依赖生图；想要 AI 图再走 Codex 生图。

## 发布前检查（本地规则，不用 AI）
- 规格：标题 ≤20 字、正文 ≤1000 字、话题 5—8 个、有封面、图片页数。
- 红线，词表自动从知识库和工作台来：`03-生意/品牌与口吻.md` 里“不能说的话”（功效词、极限词、贬低别家）；大客户模块里的企业客户名字；项目里还没上线的新品名。
- AI 腔：“不是……而是……”“总而言之”“赋能”。
- 后台字眼：文件路径、“知识库”“Skill”。

## 对话怎么接 Codex
- 页面 → 工作台本地服务 → 本机 Codex（`codex exec`，工作目录设为知识库根目录，只读沙箱，不批准任何命令）；每轮自动拼上：当前选题、当前稿件、最近几条对话、这次的要求。
- Codex 按模块自带的写作规则读资料、写稿，回复里带 `<draft>` / `<options>` / `<topics>`；工作台解析后写成新版本。**Codex 不直接写数据库。**
- Codex 不可用或超时：如实显示，可重试；示例数据里预置 1—2 个写好的创作展示结构，但不把预写内容说成现场生成。
- 每天 8 点的选题：Codex 定时任务按写作规则出 10 个，用命令写回工作台。

## 数据
建议的表：`xhs_pieces`（一篇从选题到发布是同一条：标题、角度、形式、内容支柱、来源、为什么做、状态、排期日、发布日、笔记编号）、`xhs_drafts` / `xhs_draft_versions`（标题和备选、封面大字、图片页、正文、话题、检查结果）、`xhs_messages`（对话、引用了哪些资料、对应版本）、`xhs_note_stats`（曝光、阅读、点赞、收藏、评论、涨粉、自然/投流、消耗）、`xhs_reviews`。

## 演示怎么做
1. 演示前看一眼知识库：有没有“不能说的话”、有没有至少一张写法卡。没有也能演，照实说“现在用的是通用写法”。
2. 在创作页说一句贴近老板生意的话（例：“降温了，写一篇上班族的”），看 AI 先说明按哪张写法卡写、参考了哪些文件。
3. 右边出稿件和手机预览；发布前检查把功效词、极限词、企业客户名字、还没上线的新品名拦下来，并说清改了哪里。
4. 排进日历，再到“内容”看板里看到这一篇。
