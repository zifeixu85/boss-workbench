# 配方：大客户跟进

适合高客单、老板亲自跟客户的生意（企业团购、定制、专业服务、门店 VIP）。在个人工作台已有的“客户”上加深：不只记阶段，还要记住每个客户是什么样的人、买过什么、答应过什么、什么时候该关心一下。

## 三行需求（示例）
- 要什么：每位大客户一页看全——阶段、喜好、生日、买过什么、每次聊了什么、答应过什么；新的聊天和纪要能让 AI 提取进去；到了该联系、该关怀的时候提醒我，并给我一段祝福或跟进的草稿。
- 什么不能动：知识库里客户文件的原文；首页布局。
- 怎么算好：打开任何一位大客户都能在 10 秒内说出“他在意什么、上次聊到哪、我答应了什么”；这周该联系的人首页能看到。

## 页面

| 页面 | 第一屏 | 能做什么 |
|---|---|---|
| 客户列表 | 状态页签（全部 / 新线索 / 方案报价 / 待复购 / 售后 / 门店 VIP）、表格或卡片：名称、联系人、阶段、累计消费、上次联系、下次跟进、标签（久未联系、有新材料、生日临近） | 搜索、排序；点名称打开客户抽屉，或进整页 |
| 跟进看板 | 按阶段分列，卡片：名称、联系人、这单多少、下次跟进日期 | 拖动换阶段；卡片上不放下拉 |
| 客户详情（整页 + 抽屉） | 头部：名称、联系人与决策人、阶段、来源、累计消费、上次联系、下次跟进；页签：概况 / 往来记录 / 订单与消费 / 关怀 / 答应过的事 | 记一笔跟进、改下次跟进、生成关怀草稿 |
| 关怀与回访 | 未来 30 天的生日、纪念日、节日（立冬、春节）和“太久没联系”的人；每人一条建议：送什么、怎么说 | 复制草稿、在 Codex 里改、标记已发 |
| 新材料提取 | 粘贴，或选择工作台收件箱 / 知识库 `00-收件箱/` 里的聊天、纪要（粘贴的原文同时存进 `00-收件箱/`）；AI 提取：你答应了什么、对方现在怎么想、还担心什么、看得出要不要买、下一步谁做什么；和老板规则冲突的标黄 | 确认写入（往来记录 + 待办 + 下次跟进），或改一改 |

## 概况页签放什么
按老板跟进时会问的几句话排：这家谁拍板、谁跟我对接；他们要什么、担心什么；买过什么、我答应过什么；最近聊到哪、下一步做什么；交货、开票、收货地址这些硬条件。再加一张“喜好卡”：口味、包装、送礼对象、禁忌；“重要日子”：生日、公司年会、合作纪念日。

## 数据
| 数据 | 从哪来 | 谁写 |
|---|---|---|
| 客户基本信息、喜好、重要日子 | 知识库 `04-客户/` 的客户文件 | 导入时读；改动经老板确认后交给 boss-kb 写回 |
| 阶段、下次跟进、提醒 | 工作台 | 网页或 Codex 命令 |
| 往来记录 | 工作台（关键往来同时追加到知识库客户文件的往来记录） | 新材料提取、记一笔 |
| 订单与消费 | 工作台（企业茶礼订单）；零售订单汇总从经营模块来 | 导入或手记 |
| 关怀建议 | AI 按喜好、重要日子、买过什么生成草稿 | Codex，老板自己发 |

建议的表：`clients` 加列（来源、累计消费、生日、喜好 JSON）、`client_orders`（日期、商品、份数、单价、金额、状态）、`client_logs`（日期、渠道、内容、答应了什么、顾虑、来源文件）、`client_promises`（答应了什么、给谁、哪天前、状态）、`client_care`（日子、类型、建议、草稿、状态）。

## 规矩
- “我先考虑一下”“再看看”不写成成交；阶段只在老板确认后改。
- 口头答应的价格、交期、赠品，和知识库 `05-方法与判断/` 里的判断规则对不上时标黄，问老板；老板说“这次是例外”或“规则要改”，在 `90-持续生长/待确认的发现.md` 追加一条，不直接改规则。
- 关怀和跟进的消息只出草稿，老板自己发；不读取微信。
- 客户手机号、住址等不放进截图和演示。

## 演示怎么做
1. 挑收件箱里一份还没整理的客户聊天或通话纪要，放进“新材料提取”。演示的人不先说里面有什么，看 AI 自己提。
2. 看提取结果分没分清：你答应了什么（给谁、什么、哪天前）、对方现在怎么想、还担心什么、哪些只是“再考虑一下”（不能写成成交）、下一步谁做什么。
3. 和知识库里的判断规则、报价口径对不上的，有没有标黄、问你；有没有自己改规则（不该改）。
4. 你点“确认”后，才写进往来记录、待办和下次跟进。
5. 打开“关怀与回访”：未来 30 天的生日、纪念日只从档案里来，档案里没有的不编；关怀草稿只用档案里记着的喜好，由你自己发。

## 几条硬要求（借鉴）
- 填了“下次跟进日期”，自动生成一条待办和提醒。
- 从已有字段推出提醒：生日、纪念日、上次下单时间 → “这周该问候谁”“多久没复购”。
- 改历史记录（阶段、答应过的事）要写原因，留下新旧值和时间。
- 客户卡可以借“角色卡”的样子：等级 + 四个关键数（今年成交、上次下单、待回款、多久没联系）。
