# 小红书内容中心（进阶模块包 `xhs`）

把一篇小红书笔记从选题到复盘管起来。五个页面：

| 页面 | 地址 | 做什么 |
|---|---|---|
| 今天 | `/content` | 今天发哪篇（带手机预览和发布前检查）、今天的选题、接下来几天 |
| 内容 | `/content/pieces` | 一篇从灵感池 → 已选 → 写稿中 → 待发布 → 已发布是同一条；看板 / 日历 / 列表 |
| 创作 | `/content/studio` | 左边和本机 Codex 聊，右边是稿件、手机预览、封面、版本 |
| 数据 | `/content/data` | 发出去的笔记表现，自然流量和投流分开看 |
| 复盘 | `/content/review` | 每周复盘；看出来的规律，老板点头了才存进知识库 |

另外：今日页多一张重点卡“小红书今天发什么”；“设置 → 基本信息”多一项“小红书账号名”；“数据源”里多一种导入目标“小红书笔记数据”（专业号后台导出的笔记数据表，对好字段后导进来，能撤销）；命令行多 `xhs`、`xhs-topics-add`、`xhs-notes-import`。

这是**进阶模块**（课程第二天“时间够再讲”的内容）：2026-11-12 起不在基础模板里，新搭的工作台默认没有；模块包就在老板工作台 Skill 的 `modules/xhs/`，说一句就能装。要先有“数据源与导入”（装的时候自动带上）。

## 装

在 Codex 里说“工作台装上小红书模块”。AI 会在程序文件夹里运行（模块包从老板工作台 Skill 的 `modules/` 里找）：

```bash
node scripts/module.mjs add xhs            # 模块包在别处：加 --from <文件夹或 .zip>
```

- 老板自己的工作台：装完是空的，从“记一个选题”或“AI 出选题”开始。小红书账号名：`node server/cli.ts settings-set --set xhs_name=账号名`（空着就用店名）。
- 示例库（ABC茶社，演示用）：装的时候顺手写入示例数据（41 篇已发笔记、在做的 24 篇、一周复盘、一次“平台改了列名、等你确认对照”的笔记数据导入）。全部虚构。
- 用旧模板搭的、已经在用小红书内容中心的工作台：用新版模板的 `scripts/upgrade.mjs` 升级，它会把这个模块包装上；以前的选题、稿件、笔记数据、账号名、今日页的卡都接着用（旧表由这个模块的迁移接手，不重建；旧版自带的那批代码挪进备份）。

## 换新版、拿掉

```bash
node scripts/module.mjs update xhs         # 换成模块包里的新版；老板让 Codex 改过的文件默认不盖
node scripts/module.mjs remove xhs         # 拿掉代码和菜单；选题、稿件、数据都留在数据库里，再装回来接着用
```

## 里面有什么

```text
xhs/
├── module.json          菜单、页面、今日页重点卡、账号名设置项、命令、接入点、接手旧版自带的文件
├── 需求文档.md           为什么做、流程、状态、页面、验收、还没做的
├── 配方-写作规则.md       选题、标题、正文、封面、发布前检查的写法（给 Codex 和写稿的人）
├── files/
│   ├── src/features/xhs/            五个页面、单篇抽屉、手机预览、今日页重点卡
│   ├── server/modules/xhs/          接口（/api/m/xhs/）、命令行、接入点 hooks.ts、笔记数据导入、示例数据 seed/
│   ├── server/migrations/m-xhs-*    三份迁移（接手 004_content、013_content_center*）
│   └── shared/xhs-check.ts          发布前检查（网页和服务端共用）
└── tests/install.test.mjs           装 / 用 / 拿掉 / 再装；老工作台升级
```

## 测试

先在 `template/` 里装好依赖，再在仓库根目录：

```bash
node --test modules/xhs/tests/*.test.mjs
```

## 规矩

- 示例数据全部虚构（ABC茶社·林总）；不放真实账号、客户、密钥。
- 不改核心文件；要核心多一个接入点，先在模板里补成通用的（`modules/README.md` 的“接入点”）。
- 改表：新建 `m-xhs-004-说明.sql` 这样的文件，不改已有的三份。
