# 个人助理（pa）

“使用个人助理的工作台”：一半按你关心的对象看，一半按 AI 做了什么看。

| 分区 | 页面 | 数据从哪来 |
|---|---|---|
| 我关注的 | 知识库 `知识库档案.md` 的“我关注的”表启用了类型库里的哪几类就出几页（`/focus/<类名>`）：列表（状态 + 表里指定的两个字段）、详情抽屉（现在、下一步、时间线、相关对话、相关文件） | 知识库里的对象文件，现读，不存、不改 |
| 我的助理 | 进展 `/progress` | 只读扫描本机 Codex（`~/.codex/sessions`）、Claude Code（`~/.claude/projects`）的对话记录；Codex、Claude 桌面版自己记的“看没看 / 在等你”标记 |
| | 产出 `/outputs` | 图片目录（`~/.codex/generated_images`）+ 对话里写文件动作的路径 |
| | 报告 `/reports` | 知识库 `90-日志与报告/` 里开着的那几种报告；顶上的数来自进展和产出 |
| | 助理 `/roles` | 知识库 `01-关于我/助理/` 下每个角色一个文件夹（`总助-小茶`、`分身-<名字>`、`合伙人-法务`，总助一个，分身、合伙人可以多个），三份文件（角色、规矩、记忆）齐不齐、哪天更新、记忆几条 |
| 今日 | 三张重点卡（做完等你看、在等你回话、要你确认的资料）+“总助的话” | 进展、知识库收件箱和待确认、最新一份日报（日报没开就是周报） |

格式约定在课程的《骨架与对象格式》v0.3 里（知识库和工作台共用）：

- **类型库**（`server/modules/pa/type-library.ts`，和知识库技能各带一份同样的）：项目、客户、产品、案例、作品、渠道、门店、伙伴、主题九种，每种定好状态、列表字段、常关联。只给类型库里的出页面，这一版有页面的是前四种。“我关注的”表只写类型、文件夹、确认；状态可以在“叫法”小节里换个说法（`- 客户：在谈 → 跟进中`）。加一类 = 在类型库里把它的 `page` 改成 true，不加页面。
- **对象文件开头**按 Obsidian 属性读：多个值是列表，别名用 `aliases`，关联和来源写带引号的双链 `"[[路径]]"`。v0.1 的写法（`别名`、顿号隔开）还认，页面上标“写法要改”。
- **报告**：知识库档案“报告”表里开着的才显示；没有这张表 = 只开周报；全关时报告页说怎么打开。“总助的话”开着日报取日报，否则取周报。
- **角色**（约定 v0.3）：一个角色一个文件夹“类型-名字”，有几个列几个；每个三份：`角色.md`（六个小节，合伙人再加两节）、`规矩.md`（五个小节）、`记忆.md`（超过 60 条提示归并）。总助多于一个、认不出的文件夹、旧格式都在页上说清。

## 装

```bash
node scripts/module.mjs add pa
node server/cli.ts settings-set --home pa-done,pa-waiting,pa-confirm   # 今日页顶上放这三张卡
node server/cli.ts pa-scan                                             # 第一次扫一遍（以后打开页面时自动补扫）
```

## 隐私

- 对话记录只读不改；数据库里只存元信息：标题、所在文件夹、时间、第一句的摘要（最多 80 字，像密钥的串遮掉）、写文件的路径。对话正文不存、不上传。
- Codex 的 `state_5.sqlite`、Claude 桌面版的会话信息只读其中几个标记（看没看、归档、在等你、标题），不读带内容的字段。
- 产出的文件只读不搬；图库的小图用系统自带的 `sips` 缩好放在数据库旁边的 `缩略图/`。

## 命令

`pa`、`pa-focus`、`pa-object`、`pa-progress`、`pa-outputs`、`pa-reports`、`pa-roles`（读）；`pa-scan`、`pa-report-add`、`pa-mark`（写，只写工作台自己的数据库）。`node server/cli.ts --help` 里有每条的参数。

## 状态怎么算

| 状态 | 怎么认 |
|---|---|
| 进行中 | 最后一轮还没结束，15 分钟内动过 |
| 在等我 | Claude 桌面版标着“在等你处理”；或（没有这个标记时）AI 最后一段话像在问你 |
| 做完未读 | 一轮做完了：Codex / Claude 桌面版记着你没看；不知道看没看的，48 小时内 |
| 已看 | 桌面版记着你看过，或你在工作台标过 |
| 停了 | 没做完就断了、被打断、归档了、超过 7 天没动；不知道看没看的做完超过 48 小时 |

改了状态、手动归类都只记在工作台数据库（`pa_marks`）；对话之后又有新动静，手动改的状态就不算了。
