# 个人助理（pa）

“使用个人助理的工作台”：一半按你关心的对象看，一半按 AI 做了什么看。

| 分区 | 页面 | 数据从哪来 |
|---|---|---|
| 我关注的 | 知识库 `知识库档案.md` 的“我关注的”表启用了类型库里的哪几类就出几页（`/focus/<类名>`）：列表（状态 + 表里指定的两个字段）、详情抽屉（现在、下一步、时间线、相关对话、相关文件） | 知识库里的对象文件，现读，不存、不改 |
| 我的助理 | 进展 `/progress` | 只读扫描本机 Codex（`~/.codex/sessions`）、Claude Code（`~/.claude/projects`）的对话记录；Codex、Claude 桌面版自己记的“看没看 / 在等你”标记。顶上是本周做完几件、产出几个、连续在用几天、在等你几个，和近 14 天每天做完几件的图（`/api/m/pa/pulse`） |
| | 产出 `/outputs` | 图片目录（`~/.codex/generated_images`）+ 对话里写文件动作的路径。图片排成瀑布流（按宽高整张显示）；详情能在本机打开或在访达里显示（代码类只能在访达里显示）；已经不在原处的默认不列 |
| | 报告 `/reports` | 知识库 `90-日志与报告/` 里开着的那几种报告；顶上的数来自进展和产出 |
| | 助理 `/roles` | 知识库 `01-关于我/助理/` 下每个助理一个文件夹（`总助-小茶`、`内容-小红`、`分身-<名字>`、`合伙人-法务`；总助一个，别的可以多个），三份文件 IDENTITY、SOUL、MEMORY 齐不齐、哪天更新、几行几条；深版分身多一份 `底稿.md`；`01-关于我/USER.md` 共用一份。旧的中文名（角色、规矩、记忆）还认，标“旧格式” |
| 今日 | 三张重点卡（做完等你看、在等你回话、要你确认的资料）+“总助的话” | 进展、知识库收件箱和待确认、最新一份日报（日报没开就是周报） |

格式约定在课程的《骨架与对象格式》v0.5 里（知识库和工作台共用）：

- **类型库**（`server/modules/pa/type-library.ts`，和知识库技能各带一份同样的）：项目、客户、产品、案例、作品、渠道、门店、伙伴、主题九种，每种定好状态、列表字段、常关联。只给类型库里的出页面，这一版有页面的是前五种（作品 2026-11-25 加：内容助理写的每篇存成一个作品，详情里能直接去看图文预览）。“我关注的”表只写类型、文件夹、确认；状态可以在“叫法”小节里换个说法（`- 客户：在谈 → 跟进中`）。加一类 = 在类型库里把它的 `page` 改成 true，不加页面。
- **状态分三个阶段**（约定 v0.8 第 10.2 节，2026-11-26 A梦 定）：未开始、进行中、已结束（名字在 `server/modules/pa/stages.ts` 一处，改名只改那里）。状态的叫法是用户自己的：类型库里每类原来的状态是“默认叫法”，各归一个阶段（项目“搁着”归已结束、能改回进行中；客户“沉默”归进行中，不因为久没动就算结束；案例的可对外、仅内部不套阶段）；“我关注的”表的“状态字段”写状态在哪个字段，“状态对照”写 `自己的值=阶段`。列表显示自己的叫法、按阶段分页签，对不上阶段的归“未归类”，没写的是“没标”。`pa-update` 改状态只收这一类登记过的叫法，写进去的就是这个叫法。
- **对象文件开头**按 Obsidian 属性读：多个值是列表，别名用 `aliases`，关联和来源写带引号的双链 `"[[路径]]"`。v0.1 的写法（`别名`、顿号隔开）还认，页面上标“写法要改”。
- **报告**：知识库档案“报告”表里开着的才显示；没有这张表 = 只开周报；全关时报告页说怎么打开。“总助的话”开着日报取日报，否则取周报。
- **角色**（约定 v0.5，2026-11-24 傍晚改回通用的英文名）：一个助理一个文件夹“类型-名字”，类型是总助、内容（内容助理）、分身、合伙人；每个三份：`IDENTITY.md`（它是谁：我是谁、我怎么称呼你、我管什么不管什么）、`SOUL.md`（它怎么想、怎么做事：人设四节加规矩五节，合伙人再加两节；正文超过 60 行提示“太长”）、`MEMORY.md`（每条写成 `- 2026-11-24｜规矩；原因`，没带日期的数出来；显示最早、最近一条的日期；超过 60 行提示归并）。深版分身多一份 `底稿.md`，不限行数、不算在三份里。`01-关于我/USER.md`（你是谁）所有助理共用。行数都只算不空的行，小节标题算。v0.4 的中文三份（角色、规矩、记忆）和更早的“身份 + 性格”都标“旧格式”并说清怎么改；总助多于一个、认不出的文件夹也在页上说清。

## 知识库对不上时（约定 v0.6 第 9.6 节，2026-11-25 加）

工作台不替用户改知识库的结构，只检测、说清楚：`pa-check`（页面 `/kb-check`）按知识库档案（根目录 `知识库档案.md`，或旧结构的 `01-AI协作/建库档案.md`，“位置”小节登记的路径优先）看：

- 现在就能用的页面（进展、产出不靠知识库，一直能用）；
- 要先做升级检查才能用的页面，各缺什么（没有档案、没有“我关注的”表、登记的文件夹不在、没有助理 / 报告 / 收件箱文件夹）；
- 下一步对 AI 说“检查一下我的知识库”（知识库工具的升级检查）。

老板知识库工具建的旧结构（只有 `01-AI协作/建库档案.md`，没有“我关注的”表）：按建库档案的“目录对应”推出客户（04-客户 层）、项目（06-项目 层）在哪，“我关注的”照样出页面，标待确认；文件夹没有、里面没文件的推不出来，说清楚，请用户做一次升级检查（2026-11-25 A梦 定）。

我关注的、助理、报告里有一页撑不起来时，驾驶舱上“总助的话”的位置先放“你的知识库还差几步”。搭工作台之前，Skill 也用同一份检测（模板的 `scripts/kb-check.mjs`）对老板说的那个文件夹跑一遍。

## 装

```bash
node scripts/module.mjs add pa
node server/cli.ts settings-set --home pa-done,pa-waiting,pa-confirm   # 今日页顶上放这三张卡
node server/cli.ts pa-scan                                             # 第一次扫一遍（以后打开页面时自动补扫）
```

## 隐私

- 对话记录只读不改；数据库里只存元信息：标题、所在文件夹、时间、第一句的摘要（最多 80 字，像密钥的串遮掉）、写文件的路径。对话正文不存、不上传。
- Codex 的 `state_5.sqlite`、Claude 桌面版的会话信息只读其中几个标记（看没看、归档、在等你、标题），不读带内容的字段。
- AI 用量（`pa-usage`，驾驶舱顶上“AI 用量”那一格、进展页的“AI 用量”）：Codex 记录里 `token_count` 那几行只取数字，按“累计比上一条多了多少”记到当天（累计没变的重复行不算），额度百分比照 Codex 自己写的；归档了的（`archived_sessions`，压缩的也读）也算。Claude Code 同一条回复会写好几遍，按回复编号只算一次，单独一行显示、不并进总数。工作台自己按钮调的 Codex 不留记录，不在里面。
- 产出的文件只读不搬；图库的小图用系统自带的 `sips` 缩好放在数据库旁边的 `缩略图/`。

## 命令

`pa`、`pa-focus`、`pa-object`、`pa-progress`、`pa-outputs`、`pa-reports`、`pa-roles`、`pa-check`、`pa-usage`（读）；`pa-scan`、`pa-report-add`、`pa-mark`（写，只写工作台自己的数据库）。`node server/cli.ts --help` 里有每条的参数。

## 状态怎么算

| 状态 | 怎么认 |
|---|---|
| 进行中 | 最后一轮还没结束，15 分钟内动过 |
| 在等我 | Claude 桌面版标着“在等你处理”；或（没有这个标记时）AI 最后一段话像在问你 |
| 做完未读 | 一轮做完了：Codex / Claude 桌面版记着你没看；不知道看没看的，48 小时内 |
| 做完了 | 桌面版记着你看过、你在工作台标过、归档了、超过 7 天没动；不知道看没看的做完超过 48 小时 |
| 没做完 | 7 天内、最后一轮没跑完就断了或被打断 |

改了状态、手动归类都只记在工作台数据库（`pa_marks`）；对话之后又有新动静，手动改的状态就不算了。
