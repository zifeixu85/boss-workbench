# 详情与表单

看详情、改内容、新建、删除，各有固定的做法。老板学会一次，所有模块都一样。活的示例：`/design?s=detail`（能打开一个真抽屉，在只读和编辑之间切换）。

## 五条规矩

1. **详情一律在右侧抽屉**（`components/sheet-shell.tsx` 的 `DetailSheet`）。列表还留在左边，看完一个点下一个。不要把详情做成跳走的新页面。
2. **默认只读、排好版**：像一页资料那样读。点页头的“编辑”才出现输入框。
3. **新建一律用弹窗**（`features/forms/FormDialog.tsx`）：字段少、一屏填完；回车保存、Esc 关闭。
4. **删除要二次确认**（`AlertDialog`，现成的是 `components/detail-parts.tsx` 的 `DeleteButton`），写清删了会怎样。
5. **抽屉和弹窗都由地址栏参数控制**（`app/overlay.ts`）：能分享链接、刷新不丢、按“后退”就关闭。

客户另有整页 `/clients/<id>` 和不带导航的嵌入页 `/embed/clients/<id>`（给 Codex 侧栏、浏览器小窗用），日常查看仍然用抽屉。

## 抽屉怎么搭

```tsx
<DetailSheet open onClose={() => ov.closeDetail('todo')} eyebrow="待办" title={t.title}
  meta={<><StatusBadge value={t.status} />截止 {shortDate(t.due)}</>}
  actions={<><EditToggle editing={editing} onChange={setEditing} />…</>}>
  {editing ? <编辑内容 /> : <只读内容 />}
</DetailSheet>
```

- `eyebrow` 写这是什么（客户 / 日程 / 待办 / 项目），`title` 是名字，`meta` 放状态标签和最关键的一两句，`actions` 放“编辑”开关和一两个常用动作。字段多时加 `wide`。
- 只读内容的零件（`components/detail-parts.tsx`）：`HeroFact`（最重要的一两项，大字）、`ReadRow`（一行“标签：内容”）、`Prose`（长文本，保留换行，空的时候写一句提示）、`LinkChip`（跳到关联的客户 / 项目）。分组用 `SheetSection`；长文用 `Markdown`。
- 只读时空着的字段写“未填”并提示“点‘编辑’补上”，不要显示空白。

## 两种编辑法

| 编辑法 | 用在哪 | 怎么做 |
|---|---|---|
| 字段式 | 抽屉里的一项项字段 | 点“编辑” → 每一项失焦或选好就保存（`InlineText`、`Choice`、`DatePicker` 的 `onChange` 里直接写入）→ 点“完成”回到只读。开关用 `EditToggle` |
| 整篇式 | 小红书草稿正文、长文 | 点“编辑” → 改完点“保存”或按 ⌘+回车；“取消”放弃改动回到只读 |

整篇式离开前没保存的内容要留住（切到别的草稿再回来，没保存的字还在）。

## 表单积木（`components/form.tsx`）

| 积木 | 用途 |
|---|---|
| `FormField` | 标签在上、提示在下、出错时红字替换提示 |
| `TextInput` / `TextArea` | 文字输入 |
| `Choice` | 下拉，统一用 shadcn Select；`allowEmpty` 时多一个“不关联” |
| `ClientChoice` / `ProjectChoice` | 选客户 / 选项目（自己取数据） |
| `DatePicker` | 日期，日历弹层；可清空 |
| `DateTimePicker` | 日期 + 时间，半小时一档；不选时间就是全天 |
| `MoneyInput` | 金额，单位固定“万元” |
| `issuesToErrors` | 把接口返回的字段错误变成 `{ 字段: 提示 }` |

- 字段校验用 `shared/schema.ts`（zod），网页提交前校验一次，服务端再校验一次，提示语一样。
- 提示写人话：“写个称呼，比如‘林总’”，不要“字段不能为空”。
- 写入用 `useWrite(fn, '已新增待办')`：成功自动提示并刷新所有数据，失败自动弹出错误。

## 地址栏参数

在页面里用 `useOverlay()` 打开，不要自己管 `open` 状态：

```ts
const ov = useOverlay()
ov.openDetail('client', 'c_lantuo')        // ?client=c_lantuo
ov.openNew('todo', { for: 'c_lantuo', date: '2026-10-28T15:00', text: '预填内容' })
ov.closeDetail('client'); ov.closeNew()
```

| 参数 | 作用 |
|---|---|
| `?client=` `?event=` `?todo=` `?project=` | 打开对应的详情抽屉 |
| `?new=todo` | 打开新建弹窗：todo / event / client / clientEdit / log / collect / ledger / deal / project / inbox |
| `&for=` | 新建时预先关联的客户或应收款 |
| `&date=` | 预填时间，如 `2026-10-08T15:00` |
| `&text=` | 预填内容（随手记转待办） |

页面自己的状态也写进地址栏：视图 `?view=board`、状态页签 `?status=deal`、规范页的节 `?s=charts`。

加一种新的抽屉或弹窗类型要改 `app/overlay.ts`、`app/Overlays.tsx`、`features/forms/dialogs.tsx`，属于黄区。

## 快捷键

| 键 | 作用 |
|---|---|
| ⌘K | 全局搜索 |
| T / E / L / C / N | 新建待办 / 日程 / 跟进 / 客户 / 随手记 |
| ⌘ + 回车 | 整篇式编辑里保存 |
| Esc | 关闭抽屉、弹窗 |

光标在输入框、弹窗、菜单里时单个字母不生效；Windows 把 ⌘ 换成 Ctrl。新加的页面不要再占用 T / E / L / C / N 这几个字母。
