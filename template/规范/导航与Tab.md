# 导航与 Tab

活的示例：`/design?s=nav`（布局示意图）、`/design?s=tabs`（Tab 示例）。

## 菜单只有一个来源

`src/app/nav.ts` 的 `NAV` 是唯一的菜单表。简单 / 复杂 / 顶部三种导航、手机底栏、“更多”抽屉、全局搜索都从它生成。

加一个模块 = `nav.ts` 加一项 + `app/router.tsx` 登记页面。不要在页面或外壳里另外手写菜单。

```ts
{ key: 'projects', to: '/projects', label: '项目', icon: FolderKanban, group: '日常' }
```

- `group`：分组（日常 / 客户 / 经营 / 内容 / 数据 / 资料 / 系统），复杂导航和顶部导航按它分组。
- **两个菜单项的地址不能一个是另一个的前缀**（例如 `/data` 和 `/data/imports`），否则两项会同时亮。有子页面就用 `children`；像“经营”那样平铺几项时换个前缀（汇总 `/biz`，渠道 `/channel/douyin`）。
- `children`：模块有几个子页面时写在这里（例如客户与跟进：客户列表 / 跟进清单 / 商机看板 / 大客户档案 / 应收款）。
- `badge` + `tone`：角标。只放“要你处理”的数（逾期、该跟进），用 `tone: 'warn'`；单纯的数量用 `tone: 'quiet'`。
- `short`：手机底栏放不下时的短名。

## 布局（老板在设置里切换，页面代码不用跟着改）

| 设置值 | 名字 | 样子 | 适合 |
|---|---|---|---|
| `nav_mode: simple` | 简单 | 一列菜单平铺，不分组；中等宽度只剩图标 | 模块不多、刚开始用 |
| `nav_mode: complex` | 复杂 | 侧栏分组 + 二级菜单，可收成图标栏；顶栏有位置提示和搜索 | 模块多、每天来回切换 |
| `nav_mode: top` | 顶部 | 菜单在页面上方，按分组下拉；内容区居中 | 喜欢宽屏看内容 |
| `mobile_nav: tabs` | 手机底部标签 | 常用 4 个模块在底栏（`nav.ts` 的 `MOBILE_TABS`），其余在“更多” | 大多数人 |
| `mobile_nav: drawer` | 手机汉堡菜单 | 左上角按钮拉出完整菜单 | 模块多、底栏放不下 |

页面需要知道当前布局时用 `useNavMode()`（`app/nav-mode.ts`），一般用不到。

## Tab 和左侧导航怎么分工

1. **左侧导航有子页面时，页内不再放 Tab。** 子页面已经在菜单里（`children`），页面里不要再画一排 Tab 重复它。
2. **Tab 只切换当前页的视图**：表格 / 卡片 / 看板、月 / 周 / 日、近 6 / 12 个月。不拿 Tab 跳到别的页面。
3. 简单导航没有二级菜单，所以只有它需要页内子页面导航：在 `PageHeader` 里放 `<SubTabs items={…} />`（`components/page.tsx`）。它在复杂 / 顶部导航里自动隐藏，页面不用判断。
4. 一页最多一排 Tab。需要两排时，说明页面该拆了。

## ViewTabs（视图切换）

```tsx
<ViewTabs value={view} onChange={setView} items={[
  { value: 'table', label: '表格', icon: Table2, count: 15 },
  { value: 'board', label: '看板', icon: Columns3 },
]} />
```

- 最多 4 个选项，文字越短越好；可以带图标和数量（数量是当前筛选下的条数）。
- 选中的视图写进地址栏（`?view=board`），刷新不丢、能分享。
- 筛选条件（客户、负责人、优先级）不要做成 Tab，用下拉（`Choice`）或搜索框。
- **例外：状态页签**（2026-10-10 定）。列表按状态分几类时，可以用 ViewTabs 做状态页签，带数量，例如客户列表的“全部 / 线索 / 方案报价 / 交付售后 / 待复购 / 老客户”、应收款的“逾期 / 7天内到期 …”，一点就看到跟进中的。选中的状态写进地址栏（`?status=deal`）；最多 6 类，再多改用下拉；手机上放不下时这一排在自己的框里横向滑动，页面本身不横滚。
- 手机上放不下时减少选项，不要做横向滚动的 Tab。
- 表单里两三个互斥选项（比如草稿 / 已定稿）也可以用 ViewTabs 的样子，要写 `label`。

## 页内自己的“目录”

很长的单页（比如组件规范页）可以在左边放一列页内目录、手机上变成一行横向滑动的标签，选中项写进地址栏（`?s=charts`）。这是页内导航，不是 Tab，也不要放进 `nav.ts`。
