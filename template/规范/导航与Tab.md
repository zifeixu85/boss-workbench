# 导航与 Tab

活的示例：`/design?s=nav`（布局示意图）、`/design?s=tabs`（Tab 示例）。

## 三层各管一件事（2026-10-13 定）

导航只有三层，每层管一件事，**不嵌第四层**：

| 层 | 管什么 | 长什么样 | `nav.ts` 里怎么写 |
|---|---|---|---|
| 1. 分区 | 这是哪一摊事 | 今日 / 客户 / 经营 / 内容 / 数据 / 资料。复杂导航在顶栏做页签（带这个分区要处理的数），顶部导航做下拉，简单导航做分段。设置、组件规范在“系统”分区，不占顶栏，从头像菜单进 | 每项写 `section` |
| 2. 页面 | 去哪一页 | 左栏只列当前分区的页面。页面多了可以分组：组名是**不可点**的小标题（经营里的“渠道”“数据”）；有子页面的模块，模块名就是组名（“客户与跟进”“小红书”） | 分组写 `sub`，子页面写 `children` |
| 3. 页内 Tab | 同一页换个看法 | 表格 / 看板、月 / 周 / 日、近 6 / 12 个月、按状态分类 | 不进 `nav.ts`，页面里用 `ViewTabs` |

- 分组小标题只是把页面归堆，不能点、不算一层；分组里不再套分组。
- **位置只画一层。** 顶栏不画面包屑（分区页签和左栏的高亮已经说明在哪），页头上方的小字（`PageHeader` 的 `eyebrow`）就是那一层：一般写这一页所在的分区名，可以在后面加 `· 组名`（“内容 · 小红书”“经营 · 渠道”）；首页写日期、详情页写“客户详情”这类也行。以后哪种导航在顶栏画了位置，页头就不再画。
- 现在的分区：今日（今日、日程、待办、项目、收件箱、提醒）、客户（客户与跟进的六个子页）、经营（经营汇总、渠道）、内容（小红书的五个子页）、数据（数据源与导入）、资料（知识库）、系统（设置、组件规范）。

## 菜单只有一个来源

`src/app/nav.ts` 的 `NAV` 是唯一的菜单表。复杂 / 简单 / 顶部三种导航、手机底栏、“更多”、汉堡菜单、全局搜索（页面写成“分区 › 页面”）都从它生成。

加一个模块 = `nav.ts` 加一项（写上 `section`；程序里有模块开关 `shared/modules.ts` 时再写 `module`）+ `app/router.tsx` 登记页面。不要在页面或外壳里另外手写菜单。
外壳（三种导航、底栏、“更多”、汉堡菜单、全局搜索、用户菜单）一律从 `app/nav-sections.ts` 的 `useNav()` 取菜单，不直接用 `NAV` / `SECTIONS`：模块开关关掉的模块在这里滤掉，所有导航一起不显示。

```ts
{ key: 'projects', to: '/projects', label: '项目', icon: FolderKanban, section: '今日' }
{ key: 'ch-tmall', to: '/channel/tmall', label: '天猫', icon: ShoppingBag, section: '经营', sub: '渠道' }
```

- `section`：放进哪个分区（今日 / 客户 / 经营 / 内容 / 数据 / 资料 / 系统）。一个分区的模块都拿掉或关掉了，这个分区在所有导航里自动不显示（比如基础版只有今日和资料）。新模块放进最贴近的分区；确实放不下，再在 `nav.ts` 的分区表（`SECTION_META`）里加一个，加之前先问老板。
- `sub`：二级分组名（不可点的小标题），同一分区里挨着的同名项并成一组。不写就不分组。
- `children`：模块有几个子页面时写在这里（例如客户与跟进：客户列表 / 跟进看板 / 关怀与回访 / 新材料提取 / 跟进清单 / 应收款），每个子页面带自己的 `icon`。不写 `sub` 时，模块名就是组名。
- `badge` + `tone`：角标。只放“要你处理”的数（逾期、该跟进），用 `tone: 'warn'`；单纯的数量用 `tone: 'quiet'`。分区页签上的数 = 分区里 warn 角标的合计；某项的数已经算在别的项里（渠道的异常已算进经营汇总），写 `countedIn: 'biz'`，合计时不重复加。
- `short`：手机底栏放不下时的短名（客户与跟进 → 客户、经营汇总 → 经营、小红书 → 内容）。
- `module`：这一项归哪个模块开关（id 见 `shared/modules.ts`，比如渠道、经营汇总都写 `biz`）。模块关掉，这一项在所有导航里不出现；页面本身在 `router.tsx` 里用 `gate('<id>', …)` 包住，直接打开地址时显示“还没打开”。程序里没有模块开关时这个字段不起作用。
- **当前在哪一页一律用 `resolveNav(pathname)` 算**（地址最长的那项优先，全站只亮一项；客户详情 `/clients/<id>` 这类不在菜单里的地址落在模块首页）。外壳和页面不要自己比地址。

## 布局（老板在设置里切换，页面代码不用跟着改）

| 设置值 | 名字 | 样子 | 适合 |
|---|---|---|---|
| `nav_mode: complex` | 复杂（默认） | 顶栏是分区页签（带要处理的数）；左栏只列当前分区的分组和页面，可收成图标栏：每个页面一个图标、分组之间一条细线，悬停或聚焦出名字（不靠悬停弹子菜单，平板上点一下就进那一页）；分区只有一页时不显示左栏 | 模块多、每天来回切换 |
| `nav_mode: simple` | 简单 | 一列菜单，按分区分段，只列模块（子页面用页内 `SubTabs`）；中等宽度只剩图标 | 模块不多、刚开始用 |
| `nav_mode: top` | 顶部 | 分区放在页面上方，点开下拉选页面（下拉里按分组排，组名做小标题）；内容区居中 | 喜欢宽屏看内容 |
| `mobile_nav: tabs` | 手机底部标签 | 每个分区一个入口（`nav.ts` 的 `MOBILE_TABS`：今日 / 客户 / 经营 / 内容），在分区里任何一页都亮它；模块拿掉或关掉了，空位先给还没有入口的分区（取那个分区的第一页，比如资料的知识库），还不够再按菜单顺序补，最后按分区顺序排；“更多”里按分区分段列出全部页面 | 大多数人 |
| `mobile_nav: drawer` | 手机汉堡菜单 | 左上角按钮拉出完整菜单：分区 → 分组小标题 → 页面 | 模块多、底栏放不下 |

页面需要知道当前布局时用 `useNavMode()`（`app/nav-mode.ts`），一般用不到。

**数据源与导入单独一个“数据”分区**（2026-10-13 A梦 定）：经营和小红书的数都从这里进来，所以不挂在经营下面。只开内容、不开经营时（小红书内容中心会自动带上“数据源与导入”），顶栏是 今日 / 内容 / 数据 / 资料，经营分区自动不显示。手机底栏默认四个入口是 今日 / 客户 / 经营 / 内容，数据在“更多”里；有分区没入口时按分区顺序补位。

## Tab 和左侧导航怎么分工

1. **左侧导航有子页面时，页内不再放 Tab。** 子页面已经在菜单里（`children`），页面里不要再画一排 Tab 重复它。
2. **Tab 只切换当前页的视图**：表格 / 卡片 / 看板、月 / 周 / 日、近 6 / 12 个月。不拿 Tab 跳到别的页面。
3. 简单导航只列模块，所以只有它需要页内子页面导航：在 `PageHeader` 里放 `<SubTabs items={…} />`（`components/page.tsx`），它补的是“页面”这一层，不是第四层。它在复杂 / 顶部导航里自动隐藏，页面不用判断。
4. 一页最多一排 Tab。需要两排时，说明页面该拆了。

## ViewTabs（视图切换）

```tsx
<ViewTabs value={view} onChange={setView} items={[
  { value: 'table', label: '表格', icon: Table2, count: 15 },
  { value: 'board', label: '看板', icon: Columns3 },
]} />
```

- 最多 4 个选项，文字越短越好；可以带图标和数量（数量是当前筛选下的条数）。
- 选中的视图写进地址栏（`?view=board`），刷新不丢、能分享。
- 筛选条件（客户、负责人、优先级）不要做成 Tab，用下拉（`Choice`）或搜索框。
- **例外：状态页签**（2026-10-10 定）。列表按状态分几类时，可以用 ViewTabs 做状态页签，带数量，例如客户列表的“全部 / 线索 / 方案报价 / 交付售后 / 待复购 / 老客户”、应收款的“逾期 / 7天内到期 …”，一点就看到跟进中的。选中的状态写进地址栏（`?status=deal`）；最多 6 类，再多改用下拉；手机上放不下时这一排在自己的框里横向滑动，页面本身不横滚。
- 手机上放不下时减少选项，不要做横向滚动的 Tab。
- 表单里两三个互斥选项（比如草稿 / 已定稿）也可以用 ViewTabs 的样子，要写 `label`。

## 页内自己的“目录”

很长的单页（比如组件规范页）可以在左边放一列页内目录、手机上变成一行横向滑动的标签，选中项写进地址栏（`?s=charts`）。这是页内导航，不是 Tab，也不要放进 `nav.ts`。
