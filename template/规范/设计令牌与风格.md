# 设计令牌与风格

所有颜色、字体、圆角、阴影都定义在 `src/index.css`。组件里**只写令牌类名**（`bg-card`、`text-muted-foreground`、`border-border`），不写 `#2e6b55` 这样的色值，也不写 Tailwind 自带色板（`bg-green-600`）。这样换风格时整站一起变。

活的示例：`/design?s=style`（色块旁边显示的是当前风格下的实际色值，页头的小色点可以临时预览 5 套风格）。

## 5 套风格

风格写在 `<html data-theme="…">` 上，由设置里的 `theme` 决定（`app/AppShell.tsx` 的 `applyTheme`）。默认松石不写 `data-theme`；夜墨同时加 `dark` 类。

| 值 | 名字 | 样子 | 适合 |
|---|---|---|---|
| `jade`（默认） | 松石 | 米白底、墨绿主色 | 大多数生意（ABC茶社用这套） |
| `wood` | 原木 | 暖底色、赭色主色 | 家居、餐饮、手作 |
| `navy` | 墨蓝 | 冷静理性，深色侧栏 | 咨询、贸易、制造 |
| `mono` | 素白 | 黑白灰，内容优先 | 设计、内容创作 |
| `night` | 夜墨 | 深色，图表换深色版配色 | 晚上用 |

风格的中文名和设置页一致（见 `features/settings/LookPickers.tsx` 的 THEMES）。

新加风格 = 在 `index.css` 里加一段 `:root[data-theme="…"]`，只覆盖要变的令牌；同时把它加进 `shared/schema.ts` 的 `THEMES` 和规范页。属于黄区改动。

## 界面色

| 类名 | 令牌 | 用在哪 |
|---|---|---|
| `bg-background` | `--background` | 页面底色 |
| `bg-surface-2` | `--surface-2` | 第二层底：表头、看板列、分组标题 |
| `bg-card` | `--card` | 卡片、抽屉、弹窗 |
| `text-foreground` | `--foreground` | 正文 |
| `text-muted-foreground` | `--muted-foreground` | 次要文字、说明、坐标轴 |
| `bg-muted` | `--muted` | 中性标签、代码、骨架屏 |
| `bg-primary` / `text-primary` | `--primary` | 主按钮、选中、链接；每块区域最多一处大面积 |
| `bg-accent` | `--accent` | 主色浅底：选中行、提示块 |
| `border-border` | `--border` | 边框和分隔线，一律细线 |
| `bg-sidebar` | `--sidebar` | 侧栏（墨蓝是深色侧栏） |

圆角：卡片 `rounded-xl`，按钮和输入框用组件默认。阴影：卡片 `shadow-paper`，浮起来的东西（拖动中的卡片、抽屉示意）`shadow-float`。

## 状态色：只表示状态

| 令牌 | 意思 | 例子 |
|---|---|---|
| `ok` / `ok-soft` | 好：完成、收到、签下 | 已签约、已收清、已定稿 |
| `warn` / `warn-soft` | 要注意：快到期、在等、还没定 | 待签约、7天内到期、草稿 |
| `danger` / `danger-soft` | 有问题：逾期、风险高、紧急 | 逾期、紧急、高 |
| `info` / `info-soft` | 进行中 | 进行中、需求确认、部分收款 |

- 不拿状态色当图表系列色，不拿来做装饰色块。
- 颜色之外一定有文字。
- 状态标签一律 `<StatusBadge value="…" />`。词和颜色的对照表在 `components/status.tsx`，新词先加进去（黄区），否则显示成灰色。不要用 shadcn 的 `Badge` 自己配色。

## 涨跌色：红涨绿跌

`text-rise`（红）表示涨，`text-fall`（绿）表示跌，按中国习惯。只说方向，不说好坏；好坏用文字说（“成本 ▲ 3 万，偏高”）。`Stat` 指标卡的 `delta` 已经按这个规则上色。

## 图表色：5 色，固定顺序

`--chart-1` 到 `--chart-5`：绿、橙、蓝、玫、橄榄，已用色盲模拟校验；夜墨风格有自己的深色版。第 1 个系列永远用 1 号色，不跳、不循环、不按排名上色。有先后顺序的分组用同一种颜色由浅到深（`RampBar`）。详见 [图表.md](图表.md)。

## 字体与字号

- 标题字体 `font-heading`：**所有风格都是黑体（苹方 / 微软雅黑）**，网页里不再出现宋体（2026-10-10 定）。只用在页面标题、文章标题、大数字，靠字号和粗细拉开层次。`index.css` 里各风格的 `--heading-font` 都指向黑体，新加风格也不要改成衬线字体。
- 正文字体 `font-sans`：苹方 / 微软雅黑。不引入网络字体，不加第三种字体。
- 数字要上下对齐的地方（表格、金额、日期）加 `num` 类（等宽数字）。

| 档 | 类名 | 用在哪 |
|---|---|---|
| 页面标题 | `font-heading text-[26px] font-semibold` | `PageHeader`、文章标题 |
| 大数字 | `num font-heading text-[26px] font-semibold` | `Stat` |
| 分节标题 | `font-heading text-[18px] font-semibold` | 正文 `##`、规范页分节 |
| 面板标题 | `text-[15px] font-semibold` | `Panel`、抽屉分组 |
| 正文 | `text-[14px]`（body 默认） | 列表、表格、表单 |
| 小字 | `text-[13px] text-muted-foreground` | 列表第二行、说明 |
| 注释 | `text-xs text-muted-foreground` | 截至日期和来源、眉题 |
| 标签字 | `text-[11.5px] font-medium` | `StatusBadge` |

## 写字的规矩

- 中文和数字、英文之间留空格：“3 个客户”“退款率 11%”。
- 按万元记的钱（商机、应收）用 `wan()`，1 位小数；按元记的钱（经营数据、订单）用 `yuan()`，一万以上自动写成“万”（都在 `lib/format.ts`）；日期写“10月6日”（`shortDate()`），相对日期用 `relDay()`（今天 / 明天 / 已过 2 天）。
- 空值写“—”或“暂无”，不写 0；0 只表示真的是零。
- 按钮写动词：新建待办、记一笔跟进、登记回款；不写“确定”“提交”。
