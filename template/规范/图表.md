# 图表

图表用 shadcn 的 `ChartContainer`（`components/ui/chart.tsx`，底下是 Recharts）加 `components/chart-kit.tsx` 的积木。活的示例：`/design?s=charts`（12 种，每张都写了它回答的问题、适合 / 不适合）。

## 先想问题，再选图

| 想回答的问题 | 用这种图 | 工作台里的例子 |
|---|---|---|
| 随时间怎么变？ | 折线；累积的量用面积；指标卡里用迷你走势 | 签约 vs 回款、毛利率、累计签约 |
| 谁大谁小？ | 柱状（按月、按类）；名字长或要排名用横向条；两三个量并排用分组柱 | 每月新客户、渠道贡献、收入 vs 支出 |
| 由哪几块组成？ | 堆叠柱（既看合计又看组成）；环形 / 饼图（只看谁占大头） | 每月签约按品类、品类占比 |
| 卡在哪一步？ | 漏斗：横向条，同一颜色由浅到深 | 商机阶段 |
| 完成多少了？ | 进度环，或指标卡 | 年度签约目标 |
| 哪天勤、哪天断？ | 热力日历（一列一周，单色由浅到深） | 每天的跟进次数 |
| 两个数有没有关系？ | 散点（少用） | 合同额 vs 毛利率 |

只有一个数要说时，不画图，用 `Stat` 指标卡。

## 规则（每张都要做到）

1. **标题写问题，副标题写结论。** “签下的单，钱收回来了吗？” + “这段时间签了 52.6 万，收回 36.4 万”。
2. **一张图只有一根纵轴。** 金额（万）和比例（%）不画在同一张图里，拆成两张。
3. **系列色固定顺序**：`--chart-1` 到 `--chart-5`（绿、橙、蓝、玫、橄榄）。第 1 个系列永远 1 号色；同一个东西在所有图里同一个颜色；不按大小排名上色；筛选后剩下的系列不换颜色。超过 5 个系列合并成“其他”或拆成小图。
4. **状态色（ok / warn / danger / info）不当系列色。** 涨跌用红涨绿跌（`text-rise` / `text-fall`），只表示方向。
5. **图下写截至日期和来源**：`<ChartNote>截至 10月7日 · 来源：收支流水（数据库 ledger）</ChartNote>`。当月没过完要注明“只算到今天”。
6. **暂无 ≠ 0。** 没有数据传 `null`：折线断开（`connectNulls={false}`），提示框写“暂无”（`UnitTip` 已处理）。0 只表示真的是零。
7. **饼图 / 环形最多 6 块**，小的合并成“其他”；中间写合计，旁边逐项写金额和占比。两块的饼图不如直接写两个数；几块差不多大时改用横向条。
8. **图例**：两个以上系列必须有图例（`ChartLegend` + `ChartLegendContent`，`itemSorter={null}` 保持顺序）；只有一个系列不加图例，标题说清楚。
9. **有先后的分组**（账龄、漏斗阶段）用同一种颜色由浅到深：`shape={RampBar}`。
10. **样子**：坐标轴不画刻度线和轴线（`{...AXIS}`），网格只留横线（`stroke={GRID_STROKE}`，散点可以留竖线）；柱子从 0 开始、最宽 24–28px、数据端 4px 圆角；折线 2px；面积只用 10% 淡色；堆叠的段之间留 2px 底色缝（`stroke="var(--card)" strokeWidth={2}`），不画描边。
11. **数字**：金额单位“万”，刻度写 `40万`，提示框写 `40 万`；一位小数用 `n1()`；横轴月份用 `monthTick()`（第一个月和 1 月带年份）。
12. **没有数据时不画空坐标轴**，放 `EmptyNote` 写下一步怎么做。

## 最小写法

```tsx
const config = {
  signed: { label: '签约', color: 'var(--chart-1)' },
  collected: { label: '回款', color: 'var(--chart-2)' },
} satisfies ChartConfig

<Panel title="签下的单，钱收回来了吗？" desc="这段时间签了 52.6 万，收回 36.4 万">
  <ChartContainer config={config} className="aspect-auto h-[240px] w-full">
    <LineChart accessibilityLayer data={rows} margin={{ top: 8, right: 12, left: 0, bottom: 0 }}>
      <CartesianGrid vertical={false} stroke={GRID_STROKE} />
      <XAxis dataKey="label" {...AXIS} minTickGap={8} interval="preserveStartEnd" />
      <YAxis {...AXIS} width={48} tickFormatter={(v: number) => `${v}万`} />
      <ChartTooltip cursor={{ stroke: 'var(--border)' }} content={<UnitTip config={config} unit=" 万" />} />
      <ChartLegend itemSorter={null} content={<ChartLegendContent />} />
      <Line dataKey="signed" type="monotone" stroke="var(--color-signed)" strokeWidth={2} />
      <Line dataKey="collected" type="monotone" stroke="var(--color-collected)" strokeWidth={2} connectNulls={false} />
    </LineChart>
  </ChartContainer>
  <ChartNote>截至 10月7日 · 来源：收支流水</ChartNote>
</Panel>
```

- 颜色写 `var(--color-<key>)`（`ChartContainer` 按 config 生成），不写色值。
- 容器高度要包含横轴文字（一般 `h-[230px]`–`h-[240px]`），不要让卡片里出现小滚动条。
- 环形、进度环中间的大字用普通 HTML 叠在图上（绝对定位），字用正文颜色，不用系列色。
- 热力日历用 `div` 网格画，不用 Recharts；每格 `title` 写日期和次数，整块给一句 `aria-label`。

## 积木（`components/chart-kit.tsx`）

`AXIS`、`GRID_STROKE`、`LABEL_STYLE`（条尾数字）、`CURSOR`（柱状悬停底色）、`n1` / `round1`、`monthName` / `monthFull` / `monthTick`、`RampBar`、`UnitTip`、`ChartNote`、`EmptyNote`、`Loading`、`Failed`。
