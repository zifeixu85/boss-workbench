# 组件清单

加模块时只用下面这些积木和 `src/components/ui/` 里的 shadcn 组件。路径都从 `工作台/程序/src/` 算起。改这些文件属于黄区（`ui/` 属于红区），见 [README.md](README.md)。

## 页面骨架 `components/page.tsx`

| 组件 | 用途 |
|---|---|
| `PageHeader` | 页头：眉题（菜单分组名）、标题、一句说明、右侧操作按钮；`children` 里可放 `SubTabs` |
| `SubTabs` | 页内子页面的下划线 Tab，只在简单导航显示，其他导航自动隐藏 |
| `PageBody` | 页面内容区，统一左右边距和手机底栏留白 |
| `Panel` | 面板：标题 + 说明 + 右上角操作 + 内容 |
| `Stat` | 指标卡：数值、单位、环比（红涨绿跌）、说明；`tone` 只在数值本身是状态时用 |
| `FieldRow` | 详情里的一行“标签：内容”（放在 `<dl>` 里） |

## 切换与状态

| 文件 | 组件 | 用途 |
|---|---|---|
| `components/view-tabs.tsx` | `ViewTabs` | 当前页换一种看法（表格 / 卡片 / 看板、月 / 周 / 日），可带图标和数量 |
| `components/status.tsx` | `StatusBadge` | 状态标签，词决定颜色（对照表在同一文件） |
| | `Dot` | 列表里的小圆点，旁边一定要有文字 |
| | `EVENT_COLORS` | 日程类型的颜色，日历和列表共用 |

## 列表展示

| 文件 | 组件 | 用途 |
|---|---|---|
| `components/data-view.tsx` | `StickyTable` | 表格外壳：自带滚动框，表头吸顶 |
| | `BoardColumn` | 看板的一列：列标题吸顶，列内滚动 |
| `components/dnd-board.tsx` | `DndBoard` / `DropColumn` / `DragCard` | 看板拖拽改阶段（鼠标、触屏、键盘） |

## 详情、表单、文档

| 文件 | 组件 | 用途 |
|---|---|---|
| `components/sheet-shell.tsx` | `DetailSheet` | 右侧详情抽屉外壳：眉题、标题、meta、操作、内容；`wide` 加宽 |
| | `SheetSection` | 抽屉里的一个分组 |
| `components/detail-parts.tsx` | `EditToggle` | 抽屉的“编辑 / 完成”开关 |
| | `HeroFact` / `ReadRow` / `Prose` | 只读排版：大号信息块 / 一行标签内容 / 长文本 |
| | `InlineText` | 编辑模式里失焦或回车就保存的输入框 |
| | `LinkChip` / `DeleteButton` | 跳到关联对象的小标签 / 带二次确认的删除按钮 |
| `components/form.tsx` | `FormField` `TextInput` `TextArea` `Choice` `ClientChoice` `ProjectChoice` `DatePicker` `DateTimePicker` `MoneyInput` `issuesToErrors` | 表单积木，见 [详情与表单.md](详情与表单.md) |
| `features/forms/FormDialog.tsx` | `FormDialog` | 新建弹窗外壳：标题、说明、字段、取消 / 保存 |
| `features/forms/dialogs.tsx` | `NewTodoDialog` 等 | 各类新建弹窗（待办、日程、客户、跟进、回款、收支、商机、项目） |
| `components/markdown.tsx` | `Markdown` | 显示 Markdown：知识库文档、客户背景笔记、草稿正文；会把开头的 frontmatter 显示成键值，把相对 `.md` 链接变成知识库链接 |

## 外壳与路由（`app/`）

| 文件 | 用途 |
|---|---|
| `app/nav.ts` | 菜单唯一来源：`NAV`、分组、角标、`MOBILE_TABS`；加模块在这里加一项 |
| `app/router.tsx` | 页面登记；每个页面按需加载 |
| `app/overlay.ts` | `useOverlay()`：用地址栏参数开关详情抽屉和新建弹窗 |
| `app/Overlays.tsx` | 根据地址栏参数挂上对应的抽屉和弹窗 |
| `app/nav-mode.ts` | `useNavMode()`：当前是简单 / 复杂 / 顶部导航 |

## 数据和格式（`lib/`）

| 文件 | 用途 |
|---|---|
| `lib/api.ts` | `useApi(url)` 取数、`useWrite(fn, 成功提示)` 写入（自动提示、自动刷新）、`api.get/post/patch/put/del` |
| `lib/types.ts` | 接口返回的数据形状 |
| `lib/format.ts` | `wan()` 金额、`shortDate()` `fullDate()` `relDay()` `weekday()` 日期、`ago()` 多久以前 |
| `lib/utils.ts` | `cn()` 合并类名 |

## shadcn 原件（`components/ui/`，红区，不要改）

常用的：`button` `input` `textarea` `select` `checkbox` `switch` `toggle-group` `tabs` `table` `calendar` `popover` `dialog` `alert-dialog` `sheet` `dropdown-menu` `tooltip` `collapsible` `empty` `skeleton` `alert` `kbd` `field` `chart`。需要新的 shadcn 组件时，用 shadcn 命令添加，不要手写一个长得像的。

## 规范页本身

`features/design/`：组件规范页 `/design`。`theme-tokens.ts` 从 `index.css` 读出每套风格的令牌、`theme-preview.tsx` 负责临时预览风格（离开页面自动换回），`parts.tsx` 是规范页自己的示例卡，`sections/` 下每节一个文件（示例数据都是虚构的，不读数据库）。共用组件改了，记得在这里补示例。
