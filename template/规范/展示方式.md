# 展示方式

先想“看的人要做什么”，再选展示方式。活的示例：`/design?s=display`（同一批示例客户用 6 种方式展示）。

## 怎么选

| 方式 | 适合 | 不适合 | 工作台里 | 用什么 |
|---|---|---|---|---|
| 表格 | 字段多、要横向比较、要排序 | 主要在手机上看；每条只有一两个字段 | 客户列表、应收款、收支流水 | `StickyTable` + `components/ui/table` |
| 卡片 | 一眼看一个人或一件事的全貌；手机 | 要逐列比较数字 | 客户卡片、风险项目 | 网格 + 卡片（`rounded-xl border bg-card shadow-paper`） |
| 看板 | 有先后阶段，要看卡在哪；拖动改阶段 | 没有阶段，或阶段超过 6 个 | 商机看板、待办状态 | `BoardColumn` + `DndBoard` / `DropColumn` / `DragCard` |
| 清单 | 要一条条处理、打勾 | 要看很多字段 | 待办、随手记、该跟进 | `Checkbox` 行 + `Collapsible` 分组 |
| 时间线 | 按时间发生的记录，看来龙去脉 | 要按别的条件排序或筛选 | 跟进记录、最近改动 | 按天分组的列表，左边一条竖线 |
| 日历 | 按日期安排的事 | 没有日期的数据 | 日程、跟进日期 | 小月历 `components/ui/calendar`；完整月 / 周 / 日视图用日程页的 FullCalendar |

同一页可以用 `ViewTabs` 在其中 2–3 种之间切换（例如待办：清单 / 看板），选中的视图写进地址栏。

## 卡片的 4 种

1. **面板** `Panel`：标题 + 一块内容。图表、列表、表单都装在面板里，右上角最多一个操作。
2. **指标卡** `Stat`：一个数 + 单位 + 环比（红涨绿跌）+ 一句说明。一排 2–4 个。
3. **实体卡**：一个人或一件事的全貌——名字、状态标签、最重要的 3–4 个信息。整张卡是一个按钮，点开右侧抽屉。
4. **提示块** `Alert`（主色浅底）：临时提醒、说明。不要拿彩色大色块做装饰。

## 各方式的细则

**表格**
- 一律用 `StickyTable`：自带滚动框、表头吸顶。`maxHeight` 默认留出页头高度，页面里嵌在别的内容下面时传一个更小的值。
- 名字那一列做成按钮（键盘能点），点开右侧抽屉；不要把整行做成只能鼠标点的区域。
- 数字列右对齐、加 `num`；状态列用 `StatusBadge`；过期日期用 `text-danger`。
- 列太多先砍列，不要缩小字号。手机上表格在自己的框里横向滑动，页面本身不横滚。

**卡片网格**
- 手机一列、平板两列、宽屏三列：`grid gap-3 sm:grid-cols-2 xl:grid-cols-3`。
- 文字太长用 `truncate` 或 `line-clamp-2`，不要撑破卡片。

**看板**
- 每列一个阶段，列标题写阶段标签 + 数量 + 合计金额（`BoardColumn` 的 `meta`）。
- 列标题吸顶，列内自己滚动。改阶段只有两种办法：把卡片拖到别的列（`components/dnd-board.tsx`，鼠标、触屏、键盘都能拖），或者点开卡片在右侧抽屉里改。**卡片上不放改状态的下拉**（2026-10-10 定）。
- 手机上列竖着排；宽屏一行排开。

**清单**
- 勾选框 + 一行标题 + 第二行说明（客户、项目），右边是相对日期（`relDay`），过期的用 `text-danger` 加粗。
- 勾选是“完成”，不是删除；已完成的放进折叠的“已完成”组。

**时间线**
- 按天分组，新的在上；每条写谁、什么方式（电话 / 微信 / 面谈）、说了什么。

**日历**
- 有安排的日子在小月历上带圆点；选中某天在旁边列出当天的事。
- 一周从周一开始（`weekStartsOn={1}`），中文（`react-day-picker/locale` 的 `zhCN`）。

## 窄空间的换行规则

卡片、看板、列表行里经常一行塞几个小信息（金额、跟进日期、来源）。空间变窄时按下面的规则处理，**不允许文字超出卡片边框，也不允许把“12 万”拆成两行**：

1. **数字和单位不拆行**：金额、天数一律用 `lib/format.ts` 的 `wan()`、`relDay()`，它们在数字和单位之间用了不换行空格（NBSP）。自己拼字符串时也用 `NBSP`。
2. **小信息整块换行**：一行里的几个小信息放进 `MetaRow`（`components/data-view.tsx`）。每一项自己不换行，放不下时整项掉到下一行，项与项之间横向 12px、纵向 4px。
3. **名称类文字**：客户名、标题一行放不下用省略号（`truncate`），说明类最多两到三行（`line-clamp-2` / `line-clamp-3`）。外层容器必须有 `min-w-0`，否则省略号不生效、内容会把卡片撑破。称呼和补充说明并排时，称呼 `shrink-0`，补充说明 `truncate`。
4. **看板列有最小宽度**：用 `Board` 包住各列，每列最小 228px（示例页 200px）。屏幕放不下时整个看板在自己的框里左右滑动，手机上按列吸附，不把列挤扁。
5. **列标题**：状态在左，数量和合计在右；空间不够时数量合计整体换到第二行（`BoardColumn` 已处理）。
6. **大数字**：卡片右上角的金额 `whitespace-nowrap`，宁可把名字省略，也不把金额折行。

## 吸顶与滚动

- 长表格用 `StickyTable`，看板用 `BoardColumn`，都已经处理好吸顶。
- 页面里其他要吸顶的东西（分组标题、右侧栏）用 `top-(--sticky-top)` 或 `top-[calc(var(--sticky-top)+1rem)]`。`--sticky-top` 在 `index.css` 里定义，顶部导航布局下等于导航栏高度，其他布局是 0。
- 手机（375 宽）页面不能横向滚动；宽内容（表格、看板、横向标签）在自己的框里滑动。

## 空 / 加载 / 出错

- **空**：整块为空用 `components/ui/empty`（标题说现状 + 一句下一步 + 能直接做的按钮）；一小块为空用 `EmptyNote`（虚线框一句话）。不要只写“暂无数据”。
- **加载**：第一次取数用 `Skeleton` 画出接近真实内容的形状；后台自动刷新时保留旧内容，不要闪骨架屏。图表页整页加载可以用 `chart-kit` 的 `Loading`。
- **出错**：用 `chart-kit` 的 `Failed`（说清哪里没取到 + 重试按钮）。写入的成功和失败由 `useWrite` 自动弹 toast，文字写结果（“已新增待办”）。
